# 剧情引擎 · 剧本理解与编写蒸馏

> 2026-11-21。服务 novel-to-drama / idea-to-drama。总序见 `production-priority.md`（**剧情最高**）。  
> 【DramaSo / iamos / VideoLens / 彭子骁 / aizaow / 流媒体网 / YiteAI / Scenaloom / Socratopia】  
> **先理解再写**：写不出引擎 = 提纲，打回。集长由剧本决定（只保 ≥60s，不锁上限）。

## 一、理解六问（每集必答）

1. **内核一句**（本集真正讲什么）  
2. **主情**起终点落在哪场  
3. **反差**写明了吗  
4. **反派/对手**要什么；权力易位几次（≥1）  
5. **模式引擎**（下表主+可选辅）  
6. **玄幻/魔幻**：规则一句 + 代价/升级可见点  

外加人物四件套（主配角）：**欲望 Want / 缺陷 Flaw / 动机 Why / 弧光 Arc**；每人 ≥2 条有张力的关系线。【aizaow】  
反派须有「能共情的理由」；对手质量决定爽点上限。【aizaow】

冲突单元骨架：**要 X → 障碍 Y → 信息差/金手指应对 → 反转或代价 + 下集钩**【iamos】。一集至少一个完整小高潮，不是「一集讲一章小说」。

## 二、模式引擎

| 引擎 | 观众买什么 | 集内最低交付 |
|------|------------|--------------|
| 情感/甜宠 | 心动 | 关系电荷翻转；甜点后可跟小虐放大下次甜【YiteAI】 |
| 心理 | 自我欺骗被戳穿 | 外化动作/潜台词，禁旁白解释心理 |
| 反差爽感 | 身份/阶层错位 | 「看起来是/其实是」；观众可先知情【VideoLens】 |
| 反派压迫 | 压境与反击 | 反派目标清晰；公开场合打脸优于私下【YiteAI】 |
| 复仇/逆袭 | 翻盘 | 羞辱→隐忍→反击→释放四步齐【彭】 |
| 悬疑 | 未解 | 每集 ≤1 个新线索；悬念咬下集【aizaow】 |
| 玄幻升级 | 可见变强 | 压抑→金手指→打脸→升级→从容【InfoQ 知漫】 |
| 魔幻奇观 | 异世界规则 | 奇观服务冲突，不空放烟花 |

双层身份（明底层 / 暗战神龙王等）= 微短剧高频；揭露伴随打脸。【流媒体网】

## 三、结构三杠杆

1. **钩子**（开场数秒，黄金 3s）：DramaSo 五型——场中引爆 / 身份炸弹 / 公开羞辱 / 最后通牒 / 画面自相矛盾；iamos 四型——信息差 / 危机 / 反常 / 揭示。钩子须打中**零上下文**观众。【DramaSo / iamos】  
2. **冲突升级**：每拍改权力 / 信息 / 赌注之一；两拍踏步=删。【DramaSo】约 15s 埋小悬念顶第一流失点。  
3. **悬念**（集尾）：揭示 / 打断 / 抉择 / 反转 / 威胁【DramaSo】；或新危机 / 新信息 / 反转启动 / 身份悬念【iamos】。**先写悬念再写中段**；N 集问题 = N+1 钩子。【DramaSo / Scenaloom】

情绪曲线默认：`压抑 → 小释放 → 再压抑 → 大释放`【aizaow】。扩展时长只加密中段升级，**不延后钩子**。【DramaSo】

### 单集节拍骨架（比例，非硬锁秒数）

| 节拍 | 占比感 | 任务 |
|------|--------|------|
| 钩子 | ~前 5–10% | 引爆必须看答案的问题 |
| 铺陈反转 | 紧接 | 交代即打破第一预设 |
| 小悬念 | ~15s 级流失点 | 顶住中段流失 |
| 升级×N | 中段主体 | 每拍挪权力/信息/赌注 |
| 反转/小高潮 | 后段 | 全局重新上色或代价浮现 |
| 悬念 | 末 5–10% | 定格未解，咬下集 |

【DramaSo 节拍表压缩为比例 + iamos 四拍】成片默认 **16:9**。台词密度高时可辅独白/旁白压口型成本；先分清对白 vs 独白。【iamos】

## 四、爽点工程（蓄能 → 释放）

**爽 = 观众憋住的想要被兑现**；无憋无爽。先问：观众此刻想要什么？憋了多久？【Socratopia / iamos】

蓄能（虐/压）在升级段；释放常落小高潮。90s 级至少 1 个完整循环；头部常 2 个（中段小爽 + 高潮大爽）。【iamos】

五种放法（看戏镜头，非配额清单）【Socratopia】：

| 机制 | 观众憋的 | 释放 |
|------|----------|------|
| 压抑与释放 | 该说的话/该做的事 | 主角自己选择说出/做出 |
| 信息差 | 想知道被瞒的 | 真相落地 |
| 能力兑现 | 等金手指/手艺被看见 | 关键一击成功 |
| 公平恢复 | 要清白/公道 | 证据当众成立 |
| 认同与代偿 | 想被偏爱/被站队 | 独一份偏爱或集体站队 |

失灵：压太久走人；释放太廉价；「忍三次爆一次」被摸透。【Socratopia】  
五种可叠；判主机制看「此刻最想要什么」。不是每场都要爽——喘息戏给后面的爽扎根。【Socratopia】

### 打脸 / 解气专用

三拍：`言语进攻 → 反差揭示 → 物证/数字/第三方碾压`；揭示到碾压同场一口气。【VideoLens】  
六种可拼：扮猪吃虎 · 以子之矛 · 沉默物证 · 自我打脸 · 弱者+第三方 · 数字/身份点破。【VideoLens】  
时序感：真相埋前段；蓄压中段；核心打脸约 **后 75–90%**；回落旁观——避开正中与整点硬收。【VideoLens】  
四步篇幅感：羞辱约占四成，反击与释放约各三成。【彭】

信息差选题锁死：爽剧常**观众先于反派知情**；悬疑相反——勿混。【VideoLens / YiteAI】  
旁观者三级：扩音器 · 陪审团 · 执行者；爆点前后可各给短反应。【VideoLens】

爽点五型速查（高频）：打脸 · 逆袭 · 揭秘 · 复仇 · 甜宠。【iamos】

## 五、题材节拍重心

| 题材 | 钩子 | 中段重心 | 爽点 | 悬念 |
|------|------|----------|------|------|
| 甜宠 | 误撞/身份差 | 拉扯误会 | 撒糖/护短 | 外力威胁关系 |
| 战神/无敌 | 被轻视 | 忍让升级 | 身份曝光打脸 | 更大势力 |
| 重生 | 死亡/回归 | 先知改命 | 躲坑反杀 | 新变数 |
| 逆袭 | 被踩 | 机会成长 | 登顶可见阶层 | 旧敌反扑 |
| 悬疑 | 异常细节 | 追查误导 | 真相一层 | 还有一层 |
| 古装权谋 | 剥夺侮辱 | 设局 | 妙手揭晓 | 更大的棋 |
| 玄幻 | 受辱 | 金手指 | 打脸+突破 | 更强对手 |

【aizaow + InfoQ】多集：立局（金手指+仇敌）→ 加码 → 至暗 → 清算；每集仍须完整冲突单元+结尾钩。【iamos】付费卡点落在情绪最高未揭晓处，付后须马上兑现。【Scenaloom】

## 六、AI 易犯剧本病 → 修复

| 病 | 修复 |
|----|------|
| 铺垫癌 | 直接钩子，背景动作带 |
| 爽点晚 | 前 15s 内小爽点 |
| 脸谱反派 | 给共情理由 |
| 逻辑断 | 补过渡情绪 |
| 注水 | 一集一主爽+一副爽 |
| 无悬念 | 末尾未解问题 |
| 好事白给 | 先写憋点再写释放 |
| 整章塞一集 | 压成一个冲突单元 |

【aizaow / Socratopia / iamos】

## 七、名场面

一集 ≥1 个可截图瞬间：铺垫够低 → **一个动作**承担 → 单焦点 → 打完立刻切走别解释。【aizaow】预算优先砸名场面镜。
