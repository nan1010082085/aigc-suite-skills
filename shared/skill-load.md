# Skill 直载契约（2026-11-24）

> **本仓库不干净时的主病灶**：对话记忆 / claude-mem 摘要 / `lessons` 长文 / 旧测目录提示词，被当成「已经会了」→ **跳过 Read `SKILL.md`** → 产出压缩、偏范本。  
> 本文件规定加载顺序。违反 = 执行失败，不是「模型不懂」。

## 强制顺序（命中任务时）

1. **只打开对应 skill**：`skills/<name>/SKILL.md`（用 Read / 技能调用，禁止凭记忆复述）。
2. **再打开该 SKILL 文内点名的 references**（如 `character-prompts.md` §1.1 骨架）——按需，不整包通读 shared。
3. **按 SKILL 流程执行**；交付物结构必须等于骨架，禁止缩写。

## 禁止用下列东西顶替 SKILL

| 禁止当真相源 | 原因 |
|--------------|------|
| 本会话 / 历史会话「我记得上次」 | 记忆会压缩、串戏 |
| claude-mem / 工作区 hooks 近期摘要 | 噪声大，不是方法论 |
| `shared/lessons.md` / `lessons-archive.md` | 翻车后查阅，**禁止开场加载** |
| 旧测项目 `assets_prompts/` 薄样本 | 易抄成缩写稿 |
| 他剧定稿范本的剧情服饰句 | 只许对齐**结构**，不许抄内容 |

## lessons 降级

- **开场**：不读 lessons。  
- **FAIL / 用户纠偏后**：可查 `lessons.md` 现行条；仍以改 SKILL / 骨架为沉淀，不把 lessons 当操作手册通读。
