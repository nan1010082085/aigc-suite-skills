# 硬闸总纲（hard-gates）

> 2026-10-27 定案｜2026-11-24 蒸馏：长篇「闸门说明」拦不住模型压缩——**命令式红线**见 `shared/red-lines.md`（先读）；本文件留总纲与法务/品牌细则。  
> 可验证停机：`prompt_selfcheck` / `pre_gen_gate` / `credit_gate` **非零退出 = 禁止出片**。文档勾选不算过关。

## 最高原则：校验=合规，不是限创作（2026-11-05 用户令）

所有产出、检查、校验只拦**合规风险**，不拦**创作发挥**：

- **拦（合规）**：平台审核违禁词与惊悚浓度、品牌植入三层、AI 标识法定义务（闸 10）、未批烧积分、**压缩/偷工 skill 产出**、指令搬运失真、素材漏挂/错挂浪费积分、拼装手误、机器可读底线、**薄提纲出片（让生成模型自由发挥）**
- **不拦（创作）**：**无字数上限**、风格/叙事/镜头语言自由；检查报「缺料」只提示补哪一类字段，不规定文采怎么写
- **判定口径**：每个检查项必须能回答「不拦会有什么合规/资损后果」——答不上来的检查项=创作枷锁，删掉或降级为提示

## 零容忍清单（做了即失败）

- 「塑料 AI 感」提示词：4K / 8K / 杰作 / 超清晰 / 大师作 / wallpaper 一类废话词（用物理材质词替代）
- 硬切转场、转场无时空交代
- 品牌植入：画面 / 语音 / 字幕三层都禁
- 未经批准烧积分；指令压缩/改写后出片
- **为赶样片 / goal /「先跑通」压缩 skill 规定产出**（含把出视频锁版压成情节摘要）
- **出视频锁版缺调度·机位·运镜·动作链·声音·对话中任一类关键锚**，把空白交给生成模型自由发挥（剧本/分镜等于白写）
- 交付/发布不带 AI 生成显式标识、不主动声明；删除/篡改/伪造/隐匿标识（法定义务，闸 10）【官方：《人工智能生成合成内容标识办法》国信办通字〔2025〕2 号，2025-09-01 施行】

## 1. 花钱门（共享闸模块｜主责：出片检查，凡扣积分必过）

**花钱门是 `shared/` 里唯一共享闸模块。任何会扣积分的生成调用（生图 / 生视频 / 生音频 / 素材图），一律先过花钱门——素材图也不例外。**

操作程序（三步，顺序不可换）：

1. **报价**：生成前用**项目选定后端**的报价能力估总价，把账单（总价上限 + 逐项明细）发给用户。有多档模型时必须连档位选项一起报（不得只报单一档），更好/更贵档须提示用户可采用；档位选择权归用户。模型枚举与单价以该后端实时目录为准。
2. **用户批**：拿到用户**明确批准本批账单**后才允许执行。计划批准 ≠ 本批积分批准；素材审查通过 ≠ 可以花钱。
3. **跑**：批准后才提交扣费生成，记录批准人与积分上限。缺批准信息一律拒绝执行。

**报价留余量**：预估可能低于实扣——账单按**实估上限**报；超账单必须停下重新报价、重新获批。

**职责边界**：`shot-qa` 只做检查与报价提示，不亲自执行生成；执行走项目声明的后端（`shared/backends.md`）。**技能包不绑死某一 CLI**；某一后端的报价命令示例与档位实测表见 `shared/backends.md`（适配层）。违反花钱门 = 烧用户真金白银，零容忍。

## 2. 项目本地真相源（主责：出片检查｜2026-11-24 蒸馏）

- **真相源 = 项目本地文件**：剧本 / 分镜 / 素材映射（`assets.json` / `asset_registry.json`）/ 生成包 / 审查与生成记录，一律按项目目录落盘。
- **扣积分前须用户明确批准**（对话确认，或本地状态字段 = 项目约定的放行值，如「生成中」）；未批准禁止出图/出视频。
- **Notion 不是 skill 硬闸**：仅为外部可选同步/协作适配；未启用适配时，流程不得依赖 Notion。启用方式与坑见 `shared/lessons.md`（「仅启用 Notion 适配时」）。

## 3. 零压缩铁律（主责：出片检查｜2026-11-24 加硬）

- **本地锁版分镜/prompt 文件 = 原始数据**。出片时**逐字搬运**，禁止压缩、改写、拼装、加删标注头后再传。
- 以 SHA-256 校验「生成调用文本 ↔ 锁版文件」一致；现场拼装指令再传、把多段合成一段、给指令加/删标注头——全部违规（历史已犯过，见 `shared/lessons.md`）。
- **Agent 执行 skill 时禁止压缩 skill 产出**：不得以样片、goal、积分、篇幅为由把 `storyboard-director` / `character-studio` 等规定字段删薄。skill 写到的机位/运镜/声音/对话必须写满；**薄 = FAIL，禁止报价出片**。
- **出视频锁版信息量（2026-11-24 用户令）**：机检硬停 **≥1000 中文字/镜**（`tools/prompt_selfcheck.py` ①，FAIL=禁止 quote/run）。必须写满：调度走位、机位、运镜、分镜动作链、声音事件、对话台词——缺类 = 模型自由发挥 = 剧本白写。无上限。文档闸不够；以机检退出码为准。

## 4. 结果验真（主责：出片检查）

- 报结果**只认提交时刻之后的新 resource**：看 **`submission.resources`**（或该后端等价的新任务产物），不看 node 旧快照。
- 新 resource 的 `createdAt` 必须晚于本次提交时间戳；历史 success 资源一律不得当结果汇报。
- 轮询等待必须等新 resource 出现，禁止抓节点上第一条 success 交差。
- **验真结果回填项目本地生成记录**；仅当项目显式启用 Notion 适配时，才额外同步外部表。

## 5. 一枪一停 / 原节点重跑 / 重制不夹带（主责：出片检查）

- **一枪一停**：一次生成只干一件事，出完验完再开下一枪。
- **原节点重跑**：重试在原节点/原指令上重跑，不另起炉灶换指令。
- **重制不夹带**：重制只重制目标产物，禁止夹带改动其他镜/其他资产的生成。

## 6. 广告植入闸（三层禁｜主责：分镜创作自检 + 出片检查扫描）

真实品牌在**画面 / 语音 / 字幕**三层全部禁止，包括：

- **真实品牌名**（词表见 `shared/brand-wordlist.txt`，台词 / 旁白 / 弹幕一并扫）
- **品牌感商品包装**：指令写死「素色无品牌 + 禁包装特写」
- **品牌 Logo / 商标字样**

出片前必须过品牌扫描（`tools/brand_scan.py` 三层文本各扫一遍），命中即打回，不许「化名绕过」。

**广告合规补充（2026-10-31 入库）**：

- **极限词红线**【官方：《广告绝对化用语执法指南》，市场监管总局 2023-02-25 发布】：广告法第九条第三项「**国家级、最高级、最佳**」及近似用语禁用于台词/字幕/贴片里的品牌宣传语；六类豁免情形（仅表经营理念/主观愿望、同品牌自我比较、消费提示、商品名称或注册商标本身含绝对化用语、评定奖项称号、限定时间地域的销量事实）可对照放行；医疗/医美/药品/保健食品、招商投资、教育培训广告**从严**，不属轻微违法。
- **广告可识别性**【官方：视频号运营规范 4.6.4】：品牌露出须让观众识别为广告（4.6.4 引《广告法》《互联网广告管理办法》），隐性营销被禁。
- **禁违规产品植入**【官方：《网络短视频内容审核标准细则》(2021) 第 99 条】；**避真实商标仿冒**【官方：视频号 3.4/3.5 仿冒品牌条款、快手规范五-3 盗用商标条款】——虚构品牌不得撞真实商标。

## 7. 转场交代规则（主责：分镜创作）

场景 / 时间变化的**进场镜**必须齐备两件：

1. **时空交代**：旁白「时间，地点，场景变化逻辑」或屏幕 UI 层字幕卡；
2. **转场过渡句**：写明空间延续（镜头从上场景空间延续摇入/推入等），**明写不硬切**。

同场景多镜共用同一套场景资产，保持空间 / 光影连贯。镜文没写 = 模型自由发挥 = 转场突兀，检查发现转场裸切直接打回。

## 8. 后端方言规格（主责：分镜创作；按项目后端取方言，表见 `shared/backends.md`）

- 单次生成时长、提示词长度以所选模型的实时规格为准；超出模型上限时回到分镜设计调整，不在传输时擅自压缩或截断。
- **每时间片一个动作、一个运镜**（防画面抖）；
- 人物脸部比例与渲染风格按项目已确认的目标图和风格锁传递；不得为了未经证实的“防拦截”把写实人物自动改成 3D 或 cel-shaded。真实内容审核结果按服务端返回处理。
- **情绪必须可视化**：「泪水滑落、嘴唇微颤」而非「她很伤心」；
- **禁废话词**，用物理材质词替代；
- 参考图默认走多参考图语义，明确说「当首帧」才走首帧路径；接戏用首尾帧（模式枚举字面值见 schema），绝不用整条视频做参考。

## 9. 留存主轴与出片优先级（产出标准 + 自检）

> **创作总序（2026-11-21 用户定）**：**剧情 > 素材 > 导演出片**；闸门/预算在创作链之后。全文见 `shared/production-priority.md`。

工艺自检三轴（与总序对齐，不颠倒）：

1. **剧情与分镜**——钩子/升级/悬念成立；节拍可拆镜；打斗有交换表与易位（`plot-engines.md` / `fight-action-boarding.md`）。
2. **素材一致**——角色/场景/道具可挂 ID；优美且跨镜归一（用户与流量已验证素材相对最强，仍须服务剧情）。
3. **场景转场与导演出片**——转场交代时空；导演时间线写机位/运镜或锁定/切换（`director-natural-language.md` + `director-camera-craft.md`）；不能用炫技或构图公文补剧情。

## 10. AI 生成内容标识闸（法定义务·交付/发布前｜主责：出片检查）

> **官方，最高优先级**【官方：《人工智能生成合成内容标识办法》，网信办/工信部/公安部/广电总局，国信办通字〔2025〕2 号，**2025-09-01 施行**（全文 xwb.neu.edu.cn/2025/0316/c9646a279035/pagem.htm 转载）；同款要求：微信视频号运营规范 6.4「AI 生成/合成内容须以显著方式标识」】。法定义务不因后端/项目变化而豁免，成片交付与发布前逐项过：

1. **显式标识**：视频须在**起始画面和播放周边**加显著提示（末尾/中间可选）；导出/下载的成片文件必须含显式标识。
2. **隐式标识**：文件元数据嵌入生成属性、服务提供者、内容编号；鼓励数字水印。
3. **发布主动声明**：发布生成合成内容须**主动声明**并使用平台标识功能；**禁止删除/篡改/伪造/隐匿标识**（传播平台须核验隐式标识并加「生成/疑似生成」提示）。

- 素材层出图关水印（`watermark=false`，见 `shared/backends.md`）≠ 成品免标识——中间素材不发布，**发布成品的显式标识义务由本闸兜底**。
- 交付清单检查项见 `skills/shot-qa`（交付前检查）；任一不过 = 拒绝交付/发布。

## 11. 内容审核依据与惊悚判定（主责：出片检查扫描 + 分镜创作自检）

## 执行顺序总览（唯一顺序，任何环节不得调换）

**所有内容检查必须在报价之前完成**——「先检查再花钱」：内容有问题的镜连账单都不该出。

```

  ├ 逐字搬运对账（闸 3 零压缩）
  ├ 转场交代检查（闸 7）
  ├ 广告植入扫描（闸 6 三层）
  ├ prompt_selfcheck exit0（≥1000 字 + 机位运镜锚）+ 看点/钩子落点
  ├ 素材挂载 + ref 格式（闸 3 素材校验 · 预跑部分）
  ├ 本地锁版存在 + 用户/本地状态已放行（闸 2）
  └ 规格复核（闸 8：长度/分段/运镜/情绪/废话词）
```

## 出片五律（2026-10-29 用户令，最高优先级，凌驾本文件其他条款｜2026-11-24 蒸馏去 Notion）
