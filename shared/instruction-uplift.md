# Skill 指令增强方案（模型无关）

> 2026-11-21 用户定。  
> **Skill 出口 = 指令**（剧本条目 / 素材生图指令 / 分镜与出视频导演指令）。成片观感取决于所选模型；即梦等仅调试方言，**禁止把单一模型写成 skill 产品锁**。  
> 目标：指令更强、更好、更完整、更精准、可跨后端编译。

## 一、分层交付物（每层都要「完整可执行」）

| 层 | 完整指令必须含 | 缺了就不算强 |
|----|----------------|--------------|
| 剧本 | 六问+钩子/升级/悬念+蓄能释放；视觉化可行性；SC ID | 只有梗概无节拍 |
| 素材 | 16:9；身份锚自足；EXP/REF 发号；验收清单 | 有图无 ID/无挂镜规则 |
| 分镜 | 调度俯视句；每镜戏·机位·运镜或锁定·切法·入点；refs ID | 只有画面形容词 |
| 出视频 | 导演时间线 NL + 资产双保险 + 声音绑定；（可选）后端方言编译 | 构图公文或无切换 |

通用核心永远模型无关；长度/符号/@图语义走 `backends.md` 方言表。

## 二、优先增强项（按 ROI）

### A. 导演指令「完整度量表」（立刻可做）

每镜交付前自打分，低于满分打回（写入 selfcheck，不绑模型）：

1. 戏：主动作 + 起止态  
2. 机位：侧（地标）· 高度 · 过肩侧（若有）  
3. 运镜：四件套或「锁定不动」  
4. 切换：硬切/非常规 + 新信息  
5. 入点/ENDS ON（多镜）  
6. refs：ID + 预算内  
7. 声：台词唯一出处 + 动作声绑定  

### B. 一场戏「导演卡」模板（剧本→分镜中间件）

场级一张卡再拆镜，减少漏调度：

```text
LOC / 地标 / 轴线 / 谁在哪面朝哪
本场赌注与情绪曲线
覆盖意图：Master→OTS→反应…
音：环境床·爆点静音·BGM 段
```

### C. 黄金样例库（指令级，非成片级）

每种戏各收 1–2 条**用户认可的完整指令**（对白 / 打脸 / 打斗 / 转场 / 空镜）：

- 只存脱敏正文 + 为何合格（运镜/切换/refs）  
- 新产出对照样例 diff：缺字段=打回  
- 禁止用某模型出片观感当样例唯一标准  

### D. 后端编译薄层（已有方向，做干净）

```text
导演核心指令（NL） → prompt_compiler(backend) → 方言包
```

- 核心禁止写死 seedance 枚举名  
- 方言包：符号（<>/{}）、时长切片、ref 语法、负面通道  
- 调试用即梦时选 `backend=jimeng`，换可灵/海螺只换编译不改导演正文  

### E. 剧本指令「可拍性」自动扫（规则，非模型）

对视觉化表跑清单：主框人数、同场锁、钩子/悬念句是否空、打戏有无交换表——输出缺口列表，逼完整。

### F. 失败回流只改指令真相

clip-review / 用户纠偏 → 一条 lessons + 改对应 references；**禁止**为迁就某调试模型削弱通用导演字段。

## 三、明确不做

- 不为「某模型更好看」锁死出片模型名进 skill 硬闸  
- 不以训 LoRA 当提升路径  
- 不把调试账单/积分矩阵当成全套产品约束（可放 backends 方言附录）  

## 四、验收 skill 变强的标准

一次「指令验收」即可（可不烧视频积分）：

1. 同一集：剧本条目 + 视觉化 + 素材映射表 + 导演时间线全文  
2. 外人只读指令能画出俯视图、说出每镜机位与切点  
3. 换一个 backends 方言编译后，导演核心字段不丢
