# 出片优先级与能力提升地图（2026-11-21 用户定）

> **一部剧能不能好看：剧情 > 素材 > 导演出片。**  
> 闸门/预算是整套 skill 的合规与资损层，排在创作链之后——不替代创作，也不抢戏。  
>  
> **Skill 边界（2026-11-21 用户定）**：本套只是 **skill / 指令层**。出口=更强更完整的指令（剧本/素材/分镜/出视频）；**成片取决于用户所选模型**，skill **不限制、不绑定**出片模型。即梦等仅用于调试方言，不是套件产品出口。不训 LoRA、不改模型权重。一致性靠锁版资产 + 按镜挂 refs + 导演时间线。增强路线见 `shared/instruction-uplift.md`。

## 一、总序（不可颠倒）

```text
1. 剧情（剧本理解 + 剧本编写）
2. 素材（角色/场景/道具 · 优美且一致）
3. 导演出视频（运镜 · 视觉 · 音频 · 指令 → 成片片段）
4. 闸门与预算（合规 / 花钱门 / 关联闸 · 整套兜底）
```

好片公式：**好剧情 + 归一一致的素材 + 优秀导演**。缺剧情，运镜再炫也救不了；缺一致素材，导演只能脑补漂移；导演层负责把已成立的戏拍满——尤其打斗。

## 二、与 WorkBuddy 专家的对应

| 优先级 | 能力 | 专家 / skill | 现状（用户+流量） |
|--------|------|--------------|-------------------|
| 1 | 剧本理解与编写 | 分集编剧 · novel/idea-to-drama | **必须全面提升**；安装/留存弱，经不起验证 |
| 2 | 素材 | 视觉资产设计师 · character/scene/prop | **相对可满意**；调用最高，真实用户已帮验证 |
| 3 | 分镜细化 + 导演出片 | 分镜与出片导演 · storyboard / video-producer | **必须全面提升**；打斗/运镜/音效欠账大 |
| 4 | 闸门预算 | shot-qa / credit_gate / pre_gen_gate | 整套必有，但不等于创作质量 |

专家团「漫剧制片厂」= 编排壳：应按上表顺序调度，禁止「先堆运镜再补剧情」。

## 三、各层要蒸馏什么（检索→沉淀，持续）

### 3.1 剧情（最高）

剧本先**理解**再**编写**。理解维度（题材/模式 checklist，写进集头或场表）：

| 维度 | 问什么 |
|------|--------|
| 心理 | 欲望/恐惧/自我欺骗是什么？外化成动作与对白了吗？ |
| 情感 | 本集主情（爱/恨/愧/傲）起终点？ |
| 反差 | 题材或人物对撞句写明了吗？（见 `script-standard` 反差骨相） |
| 反派/对手 | 对手要什么？本集权力易位几次？ |
| 模式 | 甜宠/复仇/逆袭/悬疑/玄幻升级…本集用哪条引擎？ |
| 玄幻/魔幻 | 规则一句说清；代价与升级可见？禁谜语设定 |

编写硬核：钩子 / 节拍升级（权力·信息·赌注三列至少动一列）/ 悬念咬下集——细则扩写见 `script-craft.md`、`plot-engines.md`。

### 3.2 素材（第二）

优美 + 跨镜一致。三视图已稳；补维（EXP/角度/pose…）服务剧情表演，不抢剧情优先级。编号与挂参见 `id-and-registry.md`。

### 3.3 分镜（细化剧情 → 画面）

把节拍拆成可拍的镜：景别、内外景、升级落点、**打斗物理交换表**。打斗专章 `skills/storyboard-director/references/fight-action-boarding.md`；运镜/音视 `.../director-audio-visual.md`。

### 3.4 导演（运镜 · 视觉 · 音频 · 指令）

在静帧确认后出片：导演自然语言（`director-natural-language.md`）+ 机位调度避坑（`director-camera-craft.md`），再叠光影/音效。静帧表见 `still-preview-and-dsl-entry.md`。打斗：Wait→Burst→Hold。

### 3.5 闸门预算（最后）

不拦创作自由；拦资损与合规（`hard-gates.md`）。剧情/素材/导演未过关时，闸门通过 ≠ 片好看。

## 四、提升纪律

1. **每一项**（剧情理解、编写、分镜、导演视听）都值得继续全网检索 → 蒸馏进本套 skill；禁止只堆素材侧。
2. 素材「还可以」≠ 停更；但**排期上剧情与分镜/导演欠账优先于再堆风格包**。
3. 未真实验证前不报「一致性/完播提升百分之几」。
4. **跨 skill 口径**：storyboard 改写法后，必须同步 `video-producer` / `selfcheck-7` / 专家团打包文——禁止上游已纠、下游仍强制旧五段。
