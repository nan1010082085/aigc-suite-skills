## 二、skills/storyboard-director/references/prompt-format.md（PF，13 条）

> 铁律②提醒：§九 出视频指令样例块（2026-10-30 用户供参考级样例）一字不动；本单全部新增/修改均落在样例块之外的规则正文。

### PF-1【官方级】镜头写法分代（2.0 镜头N / 2.5 时间戳范式）
- 内容：**2.0 只响应镜头序号**（写「镜头1/镜头2」，禁写绝对秒数，镜头顺序优先于绝对时间——sd2-pe/2.0 口径）；**2.5 响应整数秒时间戳**，官方范式 `镜头 N｜0 秒 - 2 秒`，每镜头头字段带构图/景别/机位（官方 2.5 指南「与 2.0 差异点」+ 官方案例）；**时间戳区间必须连续**（`0-3…3-7…7-15`，不能跳段 `0-3…5-6`）；不建议用时间戳控制频率/频次。
- 留注记：`〔注记：sd2-pe「禁绝对秒数」写法已被官方分代口径校正——2.5 时间戳是官方范式〕`。
- 来源：批1 §① 尾注 + §⑤-3/4 + §③ 官方时长预算警告（**官方**：sd2-pe SKILL / 2.5 指南 / API 1520757）。
- 落点：§二 时间片规则新增「镜头写法分代」小节。

### PF-2【官方级】「每时间片一运镜」补分代注记
- 内容：§一 焦段运镜行、§二 时间片规则的「一个动作、一个运镜」补分代指引（与 CD-4 同源口径：2.0 单镜单运镜；2.5 时间戳段内单运镜、长镜头组合按段写清；1.0 可组合），留同款校正注记。
- 来源：批1 §②/§⑤-2（**官方**）。

### PF-3【官方级】强制兜底包（每次输出必挂）
- 内容：出视频指令末尾必挂：画质包（`高清，细节丰富，电影质感，色彩自然，光影柔和`）＋稳定包（`人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿`）＋字幕兜底＋水印/Logo 兜底；多人场景加**双胞胎兜底**；动漫/卡通场景加**风格锚定**；多人正面动态加**强方位约束**。
- 来源：批1 §①-7 + §⑤-5（**官方** sd2-pe SKILL）。

### PF-4【官方级】任务句式防误判
- 内容：编辑任务写「严格编辑 @视频N」、延长任务写「向后延长 @视频N」；**禁写「参考 @视频N」**（会被误判为参考任务）。
- 来源：批1 §①-3 + §⑤-17（**官方** sd2-pe/2.0 指南）。

### PF-5【官方级】断句防歧义 + 主体绑定语法
- 内容：`@图片N` 不能紧接动词（「@图片1跑向」❌→「<主体1>@图片1 跑向」✅）；主体绑定写 `<主体N>@图片N` 或「将 @图片N 中的[2-3 个稳定静态特征] 定义为 <主体N>」。
- 来源：批1 §①-2（**官方** sd2-pe SKILL）。

### PF-6【官方级】Asset ID 屏蔽
- 内容：严禁 `[asset-xxx]` 裸写进动作描述。
- 来源：批1 §①-2（**官方** sd2-pe SKILL）。

### PF-7【官方级】特殊字符规范
- 内容：音乐 `（）`、音效 `<>`、台词 `{}`、字幕/标题 `【】`；台词语种统一、小语种标注；多音字/生僻字改写为同音常用字防读错。
