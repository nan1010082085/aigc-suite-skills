### 1.1 任务类型与硬参数（API 层，官方）

| 项目 | Seedance 2.5（doubao-seedance-2-5-260628） | Seedance 2.0 系列（2-0 / fast / mini） |
|---|---|---|
| 单次时长 | 4–30 秒，`duration=-1` 模型自选；支持多轮延长 | 4–15 秒，`-1` 自选 |
| 分辨率 | 480p/720p（8bit）、1080p（10bit） | 2.0 另有 4k（10bit）；fast/mini 无 4k |
| 宽高比 | 21:9…9:16 + `adaptive`（可由输入素材定 [0.4,2.5] 任意比例） | 固定 6 档 + adaptive |
| 参考素材上限 | 50：图≤30（4K 内）+ 视频≤10（总时长≤30s）+ 音频≤10（总时长≤30s） | 15：9 图 + 3 视频 + 3 音频（总时长≤15s） |
| 输出格式 | mp4 + mov（H.264+yuv444p+PCM，编辑/延长场景保色保声画） | mp4 |
| 特有 | 样片模式（Draft）、时间戳响应、多视图主体参考、返回尾帧 | 不响应时间戳只响应镜头序号 |

**任务类型触发与限制（违反即报错，官方）：**
- 首帧/首尾帧生视频：`content.role=first_frame/last_frame`，**ratio 必须 `adaptive`**（自动对齐首帧宽高比）。也可把图设为 `reference_image` 在 prompt 写「图片1为首帧」，但此时不锁宽高比、不完全匹配。
- 视频编辑：须含 `reference_video`，`ratio=adaptive` + `duration=-1`，参考视频 4–30s，提示词须含关键词（编辑/增加/加上/删除/去掉/修改/替换/改成）。
- 视频延长：`ratio=adaptive`，提示词须含（向前/向后延长、延续、续写）。
- 编辑/延长任务指代视频直接写「`<视频N>`」，**禁止写「参考<视频N>」**（会被误判成参考任务）。
- `omni_reference_task_type`（auto/edit/extend）可前置校验；任务类型与参数不匹配报 `InvalidParameter.TaskTypeMismatch` / `TaskTypeConstraint`。
- 真人人脸参考图/视频**不支持直接上传**（2.0/2.5 均是）；官方给三条出路：信任模型产物二次创作、预置虚拟人像库、已授权真人素材。

### 1.2 提示词结构（官方公式）

- **进阶公式（2.0 官方）**：`精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件`。模型按「空间层（有什么）+ 时间层（怎么变）」两维理解，提示词要写成工程型指令而非文案形容。
- **2.5 结构（官方）**：素材指代（逐个编号绑定用途）→ 一句话概述（主体+地点+事件+题材/风格+特殊运镜）→ 具体情节描述（镜头N 或时间戳切分）→ 结尾（贯穿的机位/环境/声音/氛围）。
- **主体定义（官方）**：「将`<图片N>`中的[2–3 个清晰稳定静态特征]定义为`<主体N>`」；每次提及都要带标签，简单场景用 `<主体N>@<图片N>` 强调绑定；素材库 Asset ID **不能**替代「图片N」指代。
- **分镜时序（官方）**：写「镜头1/2/3」，每镜四要素顺序：**运镜或切换方式 → 主体动作与表情 → 位置/空间变化 → 音频信息**。2.0 对精确秒数支持不稳定，强行「0–3秒」会出异常；2.5 才响应整数秒时间戳（时间轴须连续，勿「0-3s…5-6s」跳段；勿用时间戳控频率如「一秒摇头3次」）。
- **符号规范（官方）**：音乐（括号）、音效 `<尖括号>`、台词 `{花括号}`（小语种标注语种）、字幕【方括号】。台词语言统一，禁中英混用（专有名词除外）。
- **多素材映射（2.5 官方）**：编号按上传顺序逐一文本绑定（「img1-2 是人物1，对应音频1」）；**不要只在图片上写名字**再在 prompt 直呼其名（易多人混淆/重复角色）；部分参考写明「参考哪一部分」；素材够精准时只指代、不复述画面。

### 1.3 运镜写法（官方）

- 直接用标准运镜术语即可：景别（大全景/全景/中景/近景/特写）、运镜（推/拉/摇/移/跟/环绕/俯冲/后拉/上摇/手持晃动）、机位（低角度/俯视/第一人称）；热门玩法直接写（一镜到底、希区柯克变焦、航拍、FPV、子弹时间、手持、回弹变速）。
- **一镜只写一种运镜**，不要同时要求推拉摇移（官方明确：增加画面不稳定性）。
- 小众专业词（如移焦）要转成「名词+描述性解释」；转场写清触发点+方式（「第5s快速向左横移转场（向左擦除+自然叠化）」）。
- 更细的「镜头语言」表在 Seedance 1.0 Pro 文档锚点（官方链接，本次未逐条抓取）。

### 1.4 动作/情绪写法（官方）

- 肢体细化+程度量化（缓慢抬手、用力蹬地）；**优先低缓连续小动作**，规避狂奔/大跳/剧烈翻滚；写明动作过渡承接（「借着转身惯性顺势抬手」）。
- 情绪必须外化为具体身体细节，禁抽象词：悲伤=「低头、肩膀微颤、手指攥紧衣角、泪水打转没落」等（官方有对照表）。
- 2.5：动作优先概括性描述（「双方展开近身搏斗」），只给有记忆点的动作写细节；表情写描述性语句，少用成语（「津津有味」→「脸上带着满足的笑容，大口地吃饭」）。

### 1.5 素材配置策略（官方，直接可当 skill 的素材预算）

- 素材分四种功能角色：**角色锚定 / 场景定调 / 运镜参考 / 节奏氛围**。
- 推荐配置 4–5 个素材：角色图 1–2 张（面部特写/全身）+ 场景图 1 张 + 运镜视频 1 段 + 音频 1 段。**不建议用满素材上限**——过多导致特征优先级混乱、风格冲突、主体识别模糊。
- 2.5 数量甜点：主体视频/音频参考 1–5 个（5–10s 一段）；主体图 1–8 个；视频编辑输入 ≤20s；参考图编辑 1–5 张。超过 5 个主体时用「单视图」拆多张，别塞一张多视图。

### 1.6 首尾帧 / 关键帧 / 白模 / 故事板（2.5 官方）

- **关键帧参考**（严格按分镜出片的官方通道）：分镜图逐张作为独立参考按序传入，prompt 第一句写「**以图片1至图片N的顺序作为关键帧**」。宫格图不会严格对齐分镜内容，要严按分镜就用关键帧参考。
- **多宫格分镜/故事板**：适用 ≤15 个分镜；推荐火柴人/线稿分镜，禁过度锐化/杂乱 AI 直出图、禁在分镜图上写大量文字；prompt 要补齐分镜图没有的信息并保持前后不矛盾。
- **白模参考**：粗粒度（简单几何体拼接）效果好；写明参考白模的哪个元素（运镜/动作/光影），叠加参考图时写明对应关系（「图片1灰衣男人对应视频1红色模型」）；白模外貌仍需文字详述。
- **视频延长画质劣化对策（官方）**：先把产物转白模视频再续写（提示词「将视频转为白色3D模型，人物统一为纯白3D模型，无色彩、无纹理、无阴影…」）、优先高清参考图、控制续写次数。
- **延长衔接跳变（官方）**：后期剪辑修——前段末尾删 6 帧、后段开头删 1 帧；续写以转场切镜时刻结尾，下段以切镜后新场景起始。
- **延长 vs 拼接（官方）**：单一场景文戏用延长（一镜到底）；转折/武戏/蒙太奇用分段生成再剪辑拼接；实际两者结合。

### 1.7 官方 FAQ 翻车点与对策（2.0/2.5 提示词指南，官方验证 badcase）

| 翻车点 | 官方对策 |
|---|---|
| 人脸参考不准/中途换脸 | 除全身照外**额外备一张纯面部大头照**（无表情最佳、去背景干扰）；prompt 写「面部特征参考图片1（大头照），妆造参考图片2（全身照）」；越重要的素材在 prompt 越靠前。**2.0 明确不建议人物多视图**——易被识别为多个主体 |
| 双胞胎/同款分身 | 主体逐一定义「张三（对应图片1）」；末尾加全局约束「视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物」；参考图用单人独立照片非三视图；精简 prompt（勿整剧本直灌）。注：官方承认无法 100% 规避，只能降概率 |
| 参考人物过多（>4 人） | 分组出图（每组 ≤4 人）→ 再用多张分组图做图生视频 |
| 角色与参考错位 | **参考素材按人物首次出场顺序上传**，同步调整 prompt 中图片/音频编号（2.5 官方 badcase：仅调换图片1/3 编号即修复） |
| 风格漂移（动漫漂成写实） | 提示词加明确风格约束（「2D日漫风格」「3D国风漫画」）；更稳的是先把参考图转成目标风格再生成 |
| 自动出字幕 | 约束词「保持无字幕」「避免生成任何文字或字幕」；参考素材先去字；横屏出字幕概率明显低于竖屏 |
| Logo/水印 | 「不要生成水印」「不要生成Logo」 |
| 特效不符预期 | 用参考视频定义特效（「数字2999出场方式参考视频1」），别纯文字描述 |
| 中文发音错 | 同音常用字替换（「螭龙山」→「吃龙山」） |
| 音色参考不准 | prompt 补音色描述（「使用@音频1低厚温润带细碎颗粒感中年男声的音色说」）+ 台词风格贴参考音频语气 |
| 首帧图生视频画面跳变 | 输入图裁到目标宽高像素值 + `ratio=adaptive` |
| 视频结尾噪音 | 剪辑软件音量包络线淡出 |

## ② GitHub 实证精选（仓库 / 经验 / 翻车点）

### 2.1 出片工作流仓库（社区开源）

- **sorker/ai-shotlive**（348 stars，https://github.com/sorker/ai-shotlive ）「小说→剧本→分镜→资产→关键帧→成片」工业化工作流。核心理念**关键帧驱动**：先画后动（先生成首帧+尾帧，再插值成视频）；资产约束（角色定妆照+场景概念图绑定生成，减少不连戏）；九宫格分镜（同镜 9 视角预览选首帧）；衣橱系统（多套造型保持面部一致）；生成时自动带入当前场景图+角色服装图。多厂商视频模型可插拔（Seedance/可灵/Vidu/万象/Veo/Sora）。
- **xiang186/ai-manga-video-workflow**（https://github.com/xiang186/ai-manga-video-workflow ）：Dify 工作流出结构化分镜 JSON（scene_id / image_prompt 英文 / dialogue / character_list / shot_type=close-up|medium|wide，每集 6–24 镜）→ ComfyUI（Flux/SDXL）出图 → TTS → 合成。**角色一致性用 IP-Adapter 参考图引导，权重推荐 0.7–0.9（默认 0.8）**，每角色可配独立正/负向提示词与生图参数；FAQ 明确「一致性不佳→装 IP-Adapter 插件、配 ClipVision、调高权重」。
- **zff/seedance-2.0-skill**（459 commits，https://github.com/zff/seedance-2.0-skill ，MIT）：把 Seedance 2.0 出片做成 agent skill OS，含 references/i2v-guide.md 等实操手册。要点：每素材分角色（identity/environment/motion/camera rhythm/audio tempo/style/endpoint）；**i2v 双模式**——Hold 模式（图即瞬间：铺 3–4 个微动作如眨眼/呼吸/发丝飘动，其余用正+负双重锁定「她一直坐在窗边；不站起、不转身、不出画」，运镜最多一个慢推）/ React 模式（事件反应：一个情绪拆 sub-beats，关键节拍给足 ≥2 秒，急促情绪像 glitch）；**保留语**（preserve face identity / preserve logo and label / preserve outfit and hairstyle…只锁必须锁的）；长片续写必须从**已接受片段的真实结尾**写下一镜（记录实际结束状态，不是照抄原 prompt）；五档 take 分诊、单变量重试、尝试预算。
- **seedanceprompts/seedance-prompts**（https://github.com/seedanceprompts/seedance-prompts ）：Seedance 资源总索引（prompt 库/画廊/工具/创作者）。速记共识：时间码分镜、明确运镜、写约束（no text/no watermark）、**5–15 秒是 Seedance 2.0 舒适区**。
- **ZeroLu/awesome-seedance**（450 commits，持续更新至 2026-10-30）：高保真 prompt 合集（电影/动漫/短剧/广告/VFX），社区主流写法是「Style 头 + Duration + [00-05s] Shot 1…[05-10s] Shot 2…」的时间码多镜结构，全部带成片视频对照。含 Short-form Drama & Web Series 分类。
- 另有 EvoLinkAI/awesome-seedance-2.5-guide（官方指南镜像+55 案例索引）、wanna-money/video-prompt-craft-skill（把《救猫咪》《分镜头脚本设计教程》等影视经典编成 3 个协同 Claude Skill，适配 Sora/Runway/Kling/Seedance）、Toonflow、drama-workshop、waoowaoo、xhongc/ai_story 等同类流水线（搜索所见，未逐一深抓）。

### 2.2 社区实测翻车点与对策（非官方，但有对照实验）

- **WaveSpeed 博客（社区实测）** https://wavespeed.ai/blog/posts/blog-character-consistency-seedance-2-0/ ：Seedance 2.0「保运动优先于保脸」，漂移出现在转头/手遮脸/快速 yaw、光影变化=软性改脸。对策：**参考包纪律**——3 张静帧（正/四分之三/侧，同光同表情）+ 2–3s 中性短片 + 1 张风格锚图；拼贴图（collage）无效反而像杂乱场景；混合光会把肤色平均掉。提示词：把人写成单一实体（"same character as references"）、锁 1–2 个硬特征、运动纪律=身份纪律（简单动作：走/坐/转15度/眨眼）；**负面约束比正面更被遵守**（avoid dramatic turns…）；提示词缩短 1/3 反而更稳。修复阶梯：一次只换一张参考→一次只加一条约束→动作砍到 1.5–2 秒→降背景熵。QA 清单：冻结首/中/末帧比眼距下颌、手过脸后必须复查、小 logo 翻转=脸部漂移前兆。
- **掘金《角色一致性工程化落地》（社区总结）** https://juejin.cn/post/7690490511467839514 ：一致性四层栈——①参考图驱动（定妆照+结构化角色卡+3–5 张角度参考图，全片走图生视频不走纯文生）②IP-Adapter FaceID Plus v2 + ADetailer 修中远景脸崩 ③长线 IP 训专属 LoRA（30–50 张，宣称一致性 ~97%，无第三方验证）④关键帧记忆（存关键帧给后续镜参考）。分镜提示词八要素：CHARACTER/BACKGROUND/ACTION/SCENE/CAMERA/LIGHT/TEXT/STYLE。产能口径：优化方向是压废片率而非压单次推理成本；出 30 张图精修才用 1 张是精品团队常态。
- **Marginalia 实测（带成本）** https://jinzi.cyou/posts/2026-05-09-aigc-3d-scene-and-character-lora/ ：跨镜空间一致性用 World Labs Marble 单图锚（¥10–20/场景）最优；i2i 凑多视角喂 Marble 反而拼缝鬼影（几何不严格一致）；SDXL LoRA 5 张图+800 步（约 ¥0.6/角色）能锁住「4臂3眼」级特征，但 SDXL 有写实天花板。最终工艺：**关键场景空间锚 + LoRA 锁角色 + ControlNet 控镜**。
- **CSDN 系列（社区总结，与掘金同源观点）**：LoRA（身份锚）/IP-Adapter（视觉参照迁移、FaceID 面部级、防抢戏）/关键帧记忆（时间序列锚定防漂移）三件套协同；IP-Adapter 需做参考图预处理与权重步数控制。

## ③ 角色一致性视频侧实操（官方+社区合并口径）

1. **参考图形态**：视频生成参考用「大头照（无表情、去背景）+ 全身照」双张分工绑定（官方）；2.0 官方**反对三视图/多视图**进视频参考（多主体误判→双胞胎）；2.5 官方支持多视图但 >5 主体仍建议单视图拆开传。三视图/设定卡定位是「图像侧身份锚 + 提示词外挂件」，进视频时降级为大头照+全身照组合。
2. **绑定写法**：逐素材编号文本绑定、按首次出场顺序上传、每次提及带标签（官方 badcase 验证）。
3. **约束话术**：双胞胎全局约束句、preserve 语、正+负双重锁定、负面句更被遵守（官方+社区）。
4. **运动纪律**：低缓连续小动作、一镜一运镜、关键节拍给足时间（官方+社区）。
5. **工程栈（开源 ComfyUI 路线）**：定妆照→IP-Adapter（0.7–0.9）→FaceID+ADetailer→长 IP 训 LoRA→关键帧记忆（社区）。
6. **长片一致性**：先画后动/首尾帧插值（ai-shotlive）、关键帧参考通道（官方 2.5）、从真实结尾续写（seedance-2.0-skill）、白模续写抗劣化（官方）。

## ④ 可直接写入 skill 的硬要求清单（每条注明来源）

**A. 提示词结构**
1. 八段进阶公式：精准主体+动作细节+场景环境+光影色调+镜头运镜+视觉风格+画质+约束条件（官方 2.0 指南）
2. 每镜四要素按序写：运镜/切换 → 动作表情 → 空间位置 → 音频（官方）
3. 主体定义句式「将图片N中的[2-3静态特征]定义为主体N」，全文统一标签，简单场景用 `主体N@图片N`（官方）
4. 符号规范：音乐（）音效<>台词{}字幕【】；台词单一语言（官方）
5. 2.0 用「镜头N」切镜、禁精确秒数；2.5 用整数秒时间戳且时间轴连续、禁频率控制（官方）

**B. 素材/参考图**
6. 素材四角色分工（角色锚定/场景定调/运镜参考/节奏氛围），每镜 4–5 个素材封顶，禁用满上限（官方）
7. 人脸参考=大头照+全身照双张分工绑定，重要素材前置；2.0 禁三视图进视频参考（官方）
8. 多素材映射必须文本逐一绑定编号，按人物首次出场顺序上传（官方）
9. 参考人物 >4 人先分组出图再图生视频（官方）
10. 真人人脸素材走官方三条合规通道（信任产物/虚拟人像/授权素材）（官方）

**C. 运镜与动作**
11. 一镜只写一种运镜；标准术语直写，小众词加描述性解释；转场写触发点+方式（官方）
12. 优先低缓连续小动作，动作写肢体+幅度/速度/力度，情绪外化成身体细节（官方）
13. i2v 双模式：Hold（3-4 微动作+正负双重锁定）/ React（情绪拆 beats、关键节拍≥2s）（社区 seedance-2.0-skill）

**D. 参数与任务类型**
14. 首帧/首尾帧任务 `ratio=adaptive` 强制；编辑任务 `ratio=adaptive + duration=-1` + 关键词；延长任务关键词（官方）
15. 编辑/延长指代视频直写「视频N」禁「参考视频N」（官方）
16. 时长/分辨率/素材数按 2.5 表（30s、50 素材、mov）或 2.0 表（15s、15 素材）分流（官方）

**E. 防翻车约束句（模板）**
17. 「保持无字幕」「避免生成任何文字或字幕」「不要生成水印」「不要生成Logo」（官方）
18. 双胞胎全局约束句（官方模板见 1.7）（官方）
19. 面部稳定句：「人物面部和身体比例稳定不变形，动作自然流畅，无穿模无卡顿」（官方示例 prompt 的【统一风格与约束】段）（官方）
20. 风格锁显式写（「3D国风漫画」类），防动漫漂写实（官方）

**F. 工作流**
21. 长片=分段生成+拼接为主、延长为辅；续写以切镜收尾、下段新场景起始；拼接删帧法（前-6/后-1）（官方）
22. 续写抗劣化：白模中转；控制续写次数（官方）
23. 严格按分镜出片走「关键帧参考」通道（图片1至N顺序作为关键帧），宫格只做探索（官方）
24. 先画后动/首尾帧插值 + 资产（定妆照+场景概念图）绑定生成（社区 ai-shotlive，与本流水线 storyboard-director 资产绑定契约同向）
25. 重试纪律：单变量重试、一次换一张参考/加一条约束、QA 冻结帧比对（社区 wavespeed）
26. 素材够精准时只指代不复述；prompt 精简，禁整剧本直灌（官方）

**G. 可嫁接底座**
27. 火山官方 `sd2-pe` 提示词优化 SKILL.md 可下载复用（官方）
28. 官方《Seedance 2.5 提示词模板》飞书文档可作为模板库蓝本（官方，未抓取）
