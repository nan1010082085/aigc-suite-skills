## ① 火山官方 sd2-pe SKILL.md 解析

来源：https://arkdocs.tos-cn-beijing.volces.com/files/video-generation/SKILL.md （**官方**，全文 21.8KB 已下载至 /tmp/sd2pe-SKILL.md；无 2.5 版 SKILL，sd25-pe/SKILL.md 等路径均 404 —— **官方** 实测）

这是 Seedance 2.0 官方「多模态 AI 导演」提示词优化器 skill，核心方法论可直接借鉴：

1. **空间层/时间层两维建模**：好的提示词 = 工程型指令（谁、场景、动作、运镜、顺序），不是文案型形容词。
2. **引用语法**：`@图片N/@视频N/@音频N` 按上传顺序编号；主体绑定 `<主体N>@图片N` 或「将 @图片N 中的[2-3 个稳定静态特征] 定义为 <主体N>」；**Asset ID 屏蔽**——严禁 `[asset-xxx]` 裸写进动作描述；**断句防歧义**——`@图片N` 不能紧接动词（"@图片1跑向"❌→"<主体1>@图片1 跑向"✅）。
3. **任务分类先行**：多模态参考 / 编辑 / 延长 / 组合 四类；编辑、延长任务**禁止**写"参考 @视频N"（会被误判为参考任务），要写"严格编辑 @视频N"、"向后延长 @视频N"。
4. **复杂度双轴判定**（时间维度事件密度 × 空间维度机位/场景切换）→ 路径 A（单镜一段式）vs 路径 B（≥2 分镜，严格三段论：总体设定+主体绑定 / 镜头分镜 / 风格+约束包）。
5. **八大核心要素**：精准主体、动作细节（必填）＋场景环境、光影色调、镜头运镜、视觉风格、画质、约束条件（按需，动漫风格场景"视觉风格"升为必填防漂移到写实）。
6. **动作描述四原则**：肢体细化+程度量化；优先低缓连续小动作（规避狂奔/大跳/剧烈翻滚）；补动作过渡衔接（惯性承接）；情绪具象外化（悲伤→"肩膀微颤、眼眶泛红、攥紧衣角"）。
7. **强制兜底包**（每次输出必挂）：画质包（`高清，细节丰富，电影质感，色彩自然，光影柔和`）+ 稳定包（`人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿`）+ 字幕兜底 + 水印/Logo 兜底；多人场景加**双胞胎兜底**；动漫场景加**风格锚定**；多人正面动态加**强方位约束**。
8. **素材策略**：推荐 4-5 个素材（角色图 1-2（大头照+全身照）+场景图 1+运镜视频 1+音频 1），不建议用满上限；重要素材（人脸大头照）前置；参考人物 >4 分组（每组 ≤4 人）再图生视频。
9. **人脸参考最佳实践**：大头照（仅头部无表情）+全身照，**禁用多视图/三视图**（触发双胞胎与 ID 漂移）——注意这是 2.0 口径，2.5 官方已支持多视图（见 ③）。
10. **特殊字符规范**：音乐 `（）`、音效 `<>`、台词 `{}`、字幕/标题 `【】`；台词语种统一、小语种标注；多音字/生僻字改写为同音常用字防读错。
11. **音频通道**：音色参考 `参考 @音频N 中的音色`；含旁白片尾可能截断杂音，建议剪映"音量包络线"淡出。
12. **仅四类关键歧义才打断用户**（方位/帧位不明、任务误判、运镜冲突、主体特征矛盾），其余缺失自动补全+透明披露。

**与现行 skill 的关系**：sd2-pe 是 2.0 时代产物；其"镜头顺序优先于绝对时间"（写 `镜头1/2/3`，禁写 `0–3s`）已被 2.5 部分推翻（2.5 响应整数秒时间戳，官方示例用 `镜头 N｜0 秒 - 2 秒` 复合头），引用时必须按后端分代。

## ③ 时长-质量官方/研究口径

### 各后端官方时长上限（**官方**，来源：https://www.volcengine.com/docs/82379/1520757 创建视频生成任务 API）

| 后端 | 单镜输出时长 | 备注 |
|---|---|---|
| Seedance 2.5 | **4–30s**，或 `-1`（模型在有效时长内自动选最佳时长） | 30 秒连贯直出 + 多轮延长；编辑任务仅支持 `duration=-1`，待编辑视频须 4–30s |
| Seedance 2.0 系列 | **4–15s**，或 `-1` | |
| Seedance 1.0 pro / pro fast | **2–12s** | |
| 返回值规则 | 接口返回 duration = 实际总帧数 / 24 向下取整（约数） | 计费相关，官方提醒谨慎设 -1 |

- Dreamina Web 端：Seedance 2.5 单次最长 30s，另有 **extended generation 5–180s** 模式（**官方**：https://dreamina.capcut.com/seedance/how-to-use-seedance-2-5）；Multiframes 工具 ≤10 个参考帧、每段 0–8s（同源）。
- 可灵 Video 3.0：多镜头最多 6 个分镜、各分镜时长之和=总时长（**社区引官方**）。
- Seedance 2.5 素材输入官方建议（**官方**：https://www.volcengine.com/docs/82379/2607689）：主体音视频参考 **5–10s 效果较好**，更长稳定性下降需抽卡；视频编辑输入 **20s 以内较好**；参考视频/音频各 ≤10 段且总时长各 ≤30s。
- 官方时长预算警告（2.5 指南）："指定时间段内容过多，会导致过度剪切或剧情遗漏，请注意时长安排的合理性"；"不建议用时间戳控制频率/频次"。

### 时长-质量关系的真实机制（**研究**）

- **训练-推断时长鸿沟 + 自回归误差累积**：视频基础模型通常只产 5–10s（arXiv 2606.22370 "Towards Error-Free Long Video Generation"，**研究**）；DiT 一次生成的 token 随时长增长受显存/算力与训练时长限制（知乎技术问答，**社区**）。自回归逐段生成时，上一段的噪点/瑕疵被当作"既定事实"延续，误差滚雪球（**研究**）。
- **画质塌方元凶=联合打分陷阱**（港中文+腾讯 AIPD，滚动边际蒸馏 RMD，2026-10 报道 https://www.techwalker.com/2026/1030/3204159.shtml ，**研究**）：教师模型对"历史+当前"联合打分时，为保连贯会容忍历史瑕疵并把它延续到新片段；表现为颜色发绿发紫、边缘像素化、纹理马赛克化，越往后越烂。RMD 改为逐片段独立评分后，10s→60s 质量分 84.68→84.52 几乎不掉（Self Forcing 79.12→70.94）。
- **实践口径（推测/社区共识）**：单镜控制在 5–10s、长叙事用多镜拼接或延长任务而非单镜拉满，可绕开累积退化；官方"4-30s 上限"是能力边界不是质量甜点。**注意：官方从未发布"时长越长质量越差"的公开声明**，30s 直出被官方作为卖点宣传——质量-时长曲线属研究/经验口径，写入 skill 时须区分标注。

## ⑤ 可直接写入 skill 的硬要求（全部标源）

1. **提示词字数上限**：中文 ≤500 字、英文 ≤1000 词，超出信息分散、模型漏细节（**官方** API 文档 1520757）。
2. **一镜一运镜**（2.0 稳定性规则）：单镜头只指定 1 种运镜，禁止推拉摇移叠加（**官方** sd2-pe SKILL + 2.0 指南）；1.0/2.5 长镜头可组合但须按时间结构分段（**官方** 1.0 复杂运镜示例 + 2.5 时间戳）。
3. **镜头分代写法**：Seedance 2.0 只响应镜头序号（禁绝对秒数）；Seedance 2.5 响应整数秒时间戳，官方范式 `镜头 N｜0 秒 - 2 秒` + 构图/景别/机位/日夜/内外/固定 头字段（**官方** 2.5 指南"与 2.0 差异点"+ 官方案例）。
4. **时间轴连续性**：时间戳区间必须连续（`0-3…3-7…7-15`），不能跳段（`0-3…5-6`）（**官方** 2.5 指南）。
5. **强制兜底包**：画质包+稳定包+字幕兜底+水印/Logo 兜底每次必挂；多人加双胞胎兜底；动漫加风格锚定（**官方** sd2-pe SKILL）。
6. **人脸参考**：2.0 用大头照+全身照、禁多视图（**官方** sd2-pe/2.0 指南）；2.5 支持多视图但 >5 主体时单视图更稳、多视角拆成多张单视图图输入（**官方** 2.5 指南素材表）。
7. **素材指代**：上传按**首次出场顺序**编号，图/音频索引成对（`img1-2 是人物 1，对应音频 1`）；禁止只在图片上写名字（**官方** 2.5 指南 + BytePlus V1.0 运维注记）。
8. **素材用量**：推荐 4-5 个（角色 1-2+场景 1+运镜视频 1+音频 1），不建议用满上限（**官方** 2.0 指南）；2.5 上限 50（图 ≤30 张 4K 内、视频 ≤10 段共 ≤30s、音频 ≤10 段共 ≤30s）（**官方** 2.5 指南）。
9. **情绪外化 + 低缓动作优先**：抽象情绪写成身体细节；优先低缓连续小动作；补动作惯性承接（**官方** sd2-pe/2.0 指南）；2.5 换了口径：动作**优先概括性描述**、只在记忆点写细节，表情用描述句不用成语（**官方** 2.5 指南）。
10. **眼睛发光兜底**：强烈情绪词会触发瞳孔发光，须最高优先级写"人物为正常人眼、不发光"，环境光只作用于面部轮廓（**官方** 2.5 指南 FAQ + BytePlus）。
11. **特殊字符**：音乐（）音效 <> 台词 {} 字幕【】；台词语种统一；多音字改同音常用字（**官方** sd2-pe/2.0 指南）。
12. **负向控制范围**：2.5 只支持负向控制字幕与音频（`不要字幕`、`无 bgm`、`不要任何声音`），其余一律正向描述（**官方** 2.5 指南）；Runway 同口径："request sharp, in-focus detail instead of no blur"（**官方/编辑注** BytePlus）。
13. **固定机位三重锁**：Seedance `camera_fixed` 参数（**官方** API）；提示词"固定机位，镜头不动"（**社区引可灵官方**）；Runway 官方句式 "The camera is entirely motionless for the duration of the scene, with movement only occurring from the subject" + 写出画面内应有运动（**官方** Runway）。
14. **速度修饰必写**：每个运镜词带速度/时长（缓慢/匀速/急/"slow 5-second pan right"），不写默认匀速（**官方** Runway；我们词典规则 2 一致）。
15. **宫格分镜**：≤15 格，推荐火柴人/线稿分镜、分镜上不写多字；宫格不严格对齐，要严格对齐用**关键帧参考**（"以图片 1 至图片 N 的顺序作为关键帧"）（**官方** 2.5 指南）。
16. **白模参考**：粗粒度简单几何体效果好；写明参考白模的哪个元素（运镜/动作 vs 光影）（**官方** 2.5 指南）。
17. **任务句式防误判**：编辑/延长写"严格编辑 @视频N"/"向后延长 @视频N"，禁写"参考 @视频N"（**官方** sd2-pe/2.0 指南）。
18. **真人脸限制**：Seedance 2.5/2.0 不支持直接上传含真人人脸的参考图/视频，需走虚拟人像/已授权素材通道（**官方** API 文档 1520757）。
19. **单镜时长甜点**：单镜 5–10s、超长叙事走延长/拼接（**研究+官方间接支持**：2.5 素材表"5-10s 稳"、时长预算警告；RMD 误差累积机制）——写入时标注为经验口径而非官方承诺。
20. **Dolly Zoom/移焦等小众词必须带一句描述性解释**（**官方** 2.5 指南"小众专业名词→[名词+描述性解释]"）。
