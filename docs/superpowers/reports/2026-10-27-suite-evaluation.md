# aigc-suite-skills 能力评估报告（预期版 · 2026-10-27）

> **性质声明**：本报告是建造完成时的**预期评估**，不是实测数据。套件尚未产出过一部剧；真实效果以试产验收为准（见第七节）。预期数字均标注依据。

## 一、总判断

本套件解决的是**工艺下限**——前作的三类审核打回（广告植入、转场裸切、人体畸变）全部是流程缺陷，现已各设硬闸；**不承诺播放/完播的市场上限**——播放与完播双低的根因是选材小众+内容竞争力，这取决于 IP 选择（归用户）与剧本质量，skill 只保证剧本/分镜的结构指标（钩子密度、节奏、5 秒开头）达到合格线以上。

一句话：**用它，翻车类问题应该趋近于零；爆不爆，要看选材和剧本本身。**

## 二、核心 skill 逐项预期（人物/场景已拆分为 character-studio + scene-studio；另设 5 个风格 skill，见 shared/style-library.md 索引）

| Skill | 下限（保底能到） | 上限（取决于什么） | 可量化验收 |
|-------|----------------|-------------------|-----------|
| **novel-to-drama** 小说改编 | 结构合格的分集剧本：30–120s 自然成型、每集微事件+起承转合+结尾钩子、禁一章一集硬切、人物/伏笔/名场面不走样 | 爆款剧本取决于原著选材与文学提炼的判断力——skill 给方法论与验收线，给不了审美 | 分集方案一次通过率；剧本返工率；「遮住钩子能猜到下集」测试通过 |
| **idea-to-drama** 想法创作 | 想法核心要素 100% 有落点（想法命中率对照表）；搜索补位市场冲突结构；同上结构指标 | 原创质量取决于想法本身的戏剧浓度 | 想法命中率=100%；≤2 问内出方案 |
| **storyboard-director** 分镜创作 | 提示词六要素齐、每时间片一动作一运镜、≤500 字、>15s 分段、转场必带时空交代、7 项自检拦截废话词/裸英文；镜头细切可拼接 | 分镜的「好看」——运镜设计的审美与叙事张力，词典给弹药不给枪法 | 7 项自检一次通过率；视频模型理解度（出片对题率）；后期拼接不返工 |
| **asset-studio** 素材创作 | 三视图锚点制：跨镜同脸、换装不漂移（i2i 同机位）、场景空镜纯净、零品牌包装；出图前置调研降低翻车 | 人物的「好看」与风格成熟度——风格库初版是起点，靠每次调研沉淀变强 | 一次抽卡合格率；跨镜一致性人审通过；广告植入打回=0 |
| **shot-qa** 出片检查 | 工艺类打回趋近零（品牌/转场/畸变/裸切全有闸）；花钱失控=0（fail-closed）；每分积分都有批准记录 | 只能查工艺，查不了「内容有没有趣」 | 平台打回次数；预算偏差=0；验真 100% |

## 四、预期效果量化（预估，试产校准）

- **工艺类平台打回**：前作全部打回都是工艺类 → 预期降 **80%+**（剩余风险：模型随机性、平台审核尺度变化）
- **返工率**（重制镜头占比）：返工主因是翻车+盲重跑 → 预期降 **50%+**
- **制作周期**：机械检查自动化（自检/扫描/校验）+ 断点续跑 → 单集工时预期降 **30%+**
- **播放/完播**：不给数字承诺。skill 层面只保证「5 秒开头有冲突、每集有钩子、节奏不注水」这些完播的技术前提——它们是必要条件不是充分条件

## 五、什么模型（明确建议）

**执行 LLM（跑 skill 的 Claude Code 会话）**：
- **创作密集环节**——novel-to-drama/idea-to-drama 的剧本提炼、storyboard-director 的分镜设计：用**最强模型**（Fable/Opus 级），这是产出质量的最大变量
- **机械执行环节**——shot-qa 校验、上传同步、报价执行、格式转换：中档模型（Sonnet 级）足够
- 工具脚本（lint/扫描/闸门）与模型无关

**生成模型（出图/出视频）**：
- 默认后端：出图 **seedream 4.7**（即梦）、出视频 **seedance 2.0_vip m2v**（即梦），单次 ≤15s——套件的即梦方言（中文≤500 字、参考图多参考图语义）按这对组合定；**套件不锁死后端**，可灵/海螺/小云雀/MJ/SD 等只要对应 MCP/CLI 可用即可切换，方言切换表见 `shared/backends.md`
- 写实真人题材一律转 **3D/cel-shading**（防平台拦截，也让一致性更稳）
- 若换平台：通用核心（六要素/时间片/转场/情绪可视化）不变，**方言四件**（长度/分段/参考图语义/负面通道）按 `shared/backends.md` 切换；负面通道差异见 `shared/backends.md` 与对应风格 skill

## 六、已知短板（诚实列出）

1. **风格库是初版**：3 风格×4 节基于 6 个网络源调研，深度不及实战沉淀——它的机制是「每次出图前置调研后回填」，第一轮试产后会明显变强
2. **审美上限不在工具里**：运镜词典/光影配方给的是合格线以上的工艺，导演判断、剧本品味仍是人的活
3. **生成模型随机性**：人体畸变、细节崩坏无法 100% 消除，只能靠锚点+验片+抽卡降低频率
4. **4 条 deferred 轻瑕疵**（README 用例数等）不影响使用，试产后顺手修
