# 剧本视觉化标注模板（填表式）

> 目标：为出片准备，不是润色文笔。兼容自用与外包。  
> **先过剧情理解**（`shared/plot-engines.md` 六问），再填本表「能不能拍」。  
> ID 规则：`shared/id-and-registry.md`（**SC=集，LOC=场景**）。  
> 集长：正片 ≥60s 由节拍成型，**不锁上限**。
