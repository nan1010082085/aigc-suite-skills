# 场景资产规范（空镜与光影锁定 · 场景侧）

> 字段名逐字引用 `shared/output-formats.md` §3 LOCKED 契约：`scenes:[{名, image, 光影锁定}]`。字段改名诉求一律回 output-formats.md 提。

## 一、场景资产台账

| 字段 | 含义 | 建法要点 |
|------|------|---------|
| `名` | 场景名 | 与分镜块 `素材映射[]` 的场景名逐字一致 |
| `image` | 场景图 | **纯空镜（无人）**——有人场景不能用于出视频 |
| `光影锁定` | 该场景光影锁定值 | 同场景多镜共用；`shared/lighting-system.md` 环境层+主光层写入锁定值，情绪层留给分镜逐镜微调 |

## 二、空镜铁律（所有场景图）

- **画面绝对无人物**：不出现人、人群、人潮、剪影、手——人物一律靠人物资产挂参考，有人即重出
- 道具上的文字/品牌一律「无文字、无商标、无品牌标识」（广告闸，过 `tools/brand_scan.py`）
- 场景图是该场景的**光影基调来源**：同场景所有镜头共用一张主图 + 同一光影锁定描述

## 三、一致性规则

- 同一场景全剧**只出一张主图**（必要时+一张昼/夜切换版），所有镜头共用
- 场景需要剧情变化（布置/装修/时间推移）：出**变体图**——同机位同光影，只改道具层，i2i 挂原场景图；改动程度用「保持机位/光影/空间结构不变，将 X 改为 Y」指令句控制（官方：火山方舟《图片生成 API》2026-10-14——无重绘幅度参数，指令式编辑）
- 场景图留**可行动空间**（人物将站/走的位置）；关键道具入画（门向、持物台面）——连续性靠场景资产交代
- 分镜转场交代（时间+地点）与场景资产呼应：场景名就是转场旁白里点名的地点

## 四、场景侧自检

1. 无人物（含虚化背景人群）
2. 光影与 `光影锁定` 描述一致（同场不同光=重出）
3. 可行动空间留足
4. 门向/道具摆位与前后镜连续
5. 无品牌/无文字
