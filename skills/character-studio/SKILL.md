# character-studio（人物出图 · 设定卡锚点制）

## 红线（先读·违反即停｜2026-11-24）

0. **直载**：动手前必须 Read 本文件 + `references/character-prompts.md` 所需章节（见 `shared/skill-load.md`）。禁止凭会话记忆 / lessons / 旧测 prompt 薄写。
1. **链路固定**：`一张设定卡（§1.1 文生）→ 一张表情九宫格（§1.3 图生图·必须挂该设定卡）`。禁止跳过设定卡直接出表情；禁止表情/微调独立文生另起一张脸。
2. **微调 = 引用已锁资产**：废格补拍、换装、角度、pose 一律 **图生图挂已锁 REF/EXP**；禁止「重新写一段薄提示词文生」当微调。
3. **设定卡指令禁止压缩**：必须打开并按 `references/character-prompts.md` §1.1 **完整骨架**交付（开篇风格句→【人物】→【服装与材质】→【版式与机位】七格「可见性：」→【一致性】→【排除】）。凭记忆缩写 / 缺段 = **未完成**，禁止出图。
4. **出图前自检（缺一停）**：①已读 §1.1 骨架本文 ②本角指令与骨架段序一致 ③表情节点的 ref = 本角已锁设定卡 resource/node ④未另起独立文生脸。

> 漏段、压缩、不按 skill 走 = Agent 执行失败，不是「模型不懂」。skill 有完整范本仍偏 = 没打开文件就写。

## 职责

把剧本人物变成**跨镜同人**资产：设定卡锁身份 → 挂卡出表情九宫格 → 裁切单张 EXP 供挂镜；再按需换装/角度/pose（皆挂卡）。编号见 `shared/id-and-registry.md`。

## 何时使用

- 剧本后要出人物设定卡 / 表情板 / 换装 / 角度 / pose
- 分镜 `素材映射[]` 要点名人物资产
- 用户说人物出图、三视图、表情表、一致性

## 流程（顺序不可换）

1. **清单 + CHAR ID**：外貌锚一字不差；情绪槽按 §1.3.1；发号见 registry
2. **前置调研**：`shared/pre-gen-research.md`；风格取本剧 `style-*`，禁串风格材质词
3. **设定卡（文生 · 身份锚）**：§1.1 完整骨架 → 出图 → 逐格验收 → 锁 `CHAR-xxx-REF-*`
4. **表情九宫格（图生 · 挂上一步设定卡）**：§1.3 一枪一套 → 验收同脸/情绪差 → 裁切入库 `EXP-*`；禁止默认一情绪一枪；禁止不挂卡的独立文生
5. **微调 / 补维（皆挂已锁资产）**：废格单张、§1.2 换装、§1.3b 角度、§1.3c pose —— 全部图生图挂 REF/EXP，不另起文生脸
6. **对账**：assets.json + registry；`素材映射[]` 写 ID

## 硬闸与自检

- **一致性两层**：人物基准锁身份 → 场景融合锁光影（`shared/prompt-formula.md` §二）
- **文生 / 图生分工**：仅设定卡主体允许纯文生；其后全挂卡
- 广告闸 / 花钱门 / 后端方言：见 `hard-gates.md`、`backends.md`、§2 附录
- 验收：`character-prompts.md` §4（含指令结构预检 -1）
- 一枪一停、验真只认新产物
