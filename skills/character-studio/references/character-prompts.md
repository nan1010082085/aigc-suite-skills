# 人物生图指令骨架（可直接复制）

> 五段式组装见 `shared/prompt-formula.md` §四；一致性两层控制见其 §二。风格段从**对应风格 skill** 取、负面段按 `shared/backends.md` 方言。〔…〕为占位符按人物设定填值。
> 注记（官方：火山方舟《图片生成 API》2026-10-14）：即梦/Seedream 无 negative_prompt 参数——〔负面段〕在即梦/Seedream 后端=正向排除句（「画面无 X、不要 Y」式指令句），SD 系后端有负面框才放负面词。

## 1.1 基础形象设定卡（身份锚 · 合一排版 · t2i · 随剧本阶段演进）

> **一张设定卡 = 三视图 + 表情板 + 服饰道具特写三区合一**（2026-10-28 用户定版）。本卡是**后续所有分镜/镜头的角色参考图唯一入口**——出视频时挂本卡锁人设，镜头内动作/表情/景别由出视频指令单独描述。
> **基础形象不是全剧一张**：造型/外观因剧情变化（换装/负伤/装备/形态改变）即出新卡，命名「角色-基础形象A（EP001-010）」式带阶段范围；每张卡同格式重出。

```
〔风格句〕。
〔角色名〕角色设定表、角色三视图设定稿，白色干净背景，专业影视角色原画排版。
主体：〔年龄/性别/体型/身高硬锚〕，〔核心识别点逐项写死——识别点=该角色最不可变的特征
（如：黑色LED显示屏脸/左眼小痣/面具），这是防漂的根〕；〔服装道具逐件写死：款型/颜色/材质/佩戴位置〕。
画面布局：左侧是角色全身三视图【正面、侧面、背面，标准A站姿，手脚自然张开，无动作】；
右上区域6个头部特写表情板：〔逐格表情与核心识别点绑定写死——
屏幕/异色瞳/面具类角色按该载体写（如：黄色疑惑脸、红色愤怒脸、绿色笑脸、蓝色平静脸、粉色爱心眼、白色懵圈脸）；
常规角色逐格写眉/眼/嘴/神态收束（如：平静/微笑/皱眉/含泪/震惊/大笑）〕；
右下区域是服饰道具特写分块：〔逐块写死：××纹理特写、××特写、……（3–5 块）〕。
统一光影：均匀柔和影棚柔光，无强烈阴影，方便漫剧复用；〔写实3D渲染/对应风格句〕，电影质感，细节清晰，
同一个角色，造型、配色、结构完全统一，不要变形，不要多出来多余人物，不要文字，高清4K。
```

**避坑五条（硬规则，逐条必守）**：
1. **必须写「标准A站姿/中立站姿，手脚自然张开，无动作」**——禁动态姿势，动态三视图结构必跑偏
2. **「同一个角色、造型、配色、结构完全统一，不要变形」必须在场**——AI 漫剧最头疼每张形象大变
3. **背景=纯白/浅灰纯色**，禁场景——设定图只看角色，方便喂角色参考锁人设
4. **表情板绑定角色核心识别点**：识别点是屏幕/异色瞳/面具/纹样的，表情按该载体写，禁生成真人五官冲淡识别点
5. **本卡出图后即为该基础形象阶段的角色参考图**：后续所有分镜/出视频指令都挂本卡（+该镜服装参考），才能全程形象统一

要点：外貌锚点与人物设定一字不差；t2i 抽卡 2–4 张择优后锁定 visual_id。
**排版强化（2026-10-27 Qwen-Image 实测翻车点）**：t2i 对宫格排版易无视——对策：①指令里逐格显式定位（「左侧三视图【正面、侧面、背面】+右上表情板+右下特写分块」的分区描述比「设定表」可靠）②验收必查：三视机位正交+A 站姿无动作+表情 6 格齐+特写 3–5 块齐，缺格即重抽 ③顽固时分区 i2i 拼版
**xyq 实测验证（2026-10-28 · 智能图片V2.5 Pro）**：显式排版锁有效（三格正交一次过）；合一设定卡按本模板逐区显式定位出图。
**材质词效注记（社区实证：Reddit r/StableDiffusion / Promgrammer / Civitai）**：「次表面散射/SSS」类材质词 SD 系写实侧有效、Flux 需 LoRA 补，Seedream/即梦侧无 A/B 实证（查不到）——皮肤/服装材质以具象中文描述为准，SSS 属跨模型借用勿当保证；intricate details/super detail 类细节词过用产生 busy 的「AI 感」纹理，克制使用。

## 1.2 服装三视图（模块 · i2i 挂主体 · 每套一张）

```
〔风格句〕。
同一人物换装三视图（人物长相、身材、头身比、站姿、机位、光影与参考图完全一致）：
仅更换服装为〔套装名〕——上装〔款型+颜色+细节逐件写死〕，下装〔…〕，鞋袜〔…〕，
配饰〔逐件：名称+佩戴位置+角色自身左右，材质备注〕；
图中标注：〔部件清单〕。
构图锁：排版与参考图完全一致，只换服装不换人，禁止改发型发色、禁止改身高比例、
禁止新增道具、禁止背景场景。〔负面段〕
```

要点（2026-10-28 xyq 实测修正）：**i2i 的参考图排版是锚定的**——「忽略参考图排版」这类文字指令压不住（实测输出原样复刻参考图的宫格排版）。服装三视图要的正是「排版与参考图一致」，此为正确行为；要单人格的立绘一律走 §1.7 画框锁。
**服装拆解分层写法（社区实测：mooko / catchmeta / Arcloop）**：分层展示（外套/内搭/下装/鞋）+ 装备局部放大 + 结构标注（细线引出、短硬标签、无衬线小字，如 "Ceremonial clasp" 式）+ 色板（主/辅/点缀色 + 材质标注：布料/皮革/金属）——只写「装备拆解」不写「局部放大+标注」=武器摆在旁边啥也看不清。版型逐件对应：领口/袖长/腰线/裙褶/裙摆/鞋子在三视图中一一对应；列「不可变特征」清单当硬约束；禁随机新增配饰、禁换发型、禁改服装剪裁与纹样主题。

## 1.3 表情表（i2i 挂主体 · 2×2）

```
〔风格句〕。
同一人物表情表 2×2 四格（长相身材与参考图完全一致，纯脸特写排版）：
【表情·〔人设标签〕】左上：眉，眼，嘴，神态收束。
【表情·〔人设标签〕】右上：眉，眼，嘴，神态收束。
【表情·〔人设标签〕】左下：眉，眼，嘴，神态收束。
【表情·〔人设标签〕】右下：眉，眼，嘴，神态收束。
每格表情解剖写满 25–40 字，四格差异明确；标签贴人设，禁通用「喜怒惊委屈」。
构图锁：四格均为纯脸特写、同一面部结构同一五官，禁止全身、禁止多于四格、
禁止背景、禁止文字气泡。〔负面段〕
```

写法：每格只写眉/眼/嘴/神态收束四要素——外貌由参考图锁；同脸的解药是每格表情写满写差异。

**表情表定位（社区实测：Arcloop）**：表情表是人工审阅/绘制参照与镜头表情描述素材，**不自动提升视频/跨镜一致性**——复杂参考表不会自动赋予一致能力；常规表情直接写进出图/出视频 prompt，特别夸张、模型难理解的表情才提供表情参考。一致性靠设定卡挂载+流程兜底（真实边界见 `character-asset-system.md` §五）。
**外部标准参照（社区实测：ezcharacter / Krea）**：8 格为行业标准（平静/喜/悲/怒/惊/惧/厌/自信），对话密集项目 12 格、次要角色 6 格；单行等距或 4×2、逐格贴标签、平静为基线；**嘴型显式描述**（缩略图尺寸下嘴型比眉眼更能读出情绪）；表情网格用方形画幅。现有 2×2 模板与 §1.1 六格表情板按用户定版保留，扩格需求按本参照写。

## 1.4 面部身份卡 / 色卡

```
〔角色名〕面部身份卡：正面免冠特写，中性表情，纯浅灰背景，〔五官锚点逐项〕；
旁附色卡小条：发色〔…〕/肤色〔…〕/瞳色〔…〕/常用服色〔…〕。
构图锁：仅面部特写+色卡条，无背景无道具。〔负面段〕
```

出法（社区实测：Arcloop「先锁脸再全身」）：从已确认设计（设定卡/已锁三视图）i2i 派生，禁止独立重新生成五官——特写只为把已确认的设计交代清楚，不是重新设计。

## 1.5 人物×场景融合图（一致性第二层 · i2i 挂人物基准）

```
与参考人物同一人（In the same style as the reference character），〔人物动作+表情〕，
置身于〔具体场景描述〕，人物面部光线与环境光一致，真实阴影投影，
〔景别，见 prompt-formula §三词表〕，〔风格句〕。〔负面段〕
```

## 1.6 角色参考卡（给视频层用的合成卡 · i2i 挂主体）

```
〔风格句〕。同一人物角色参考卡：正面大图为主体（腰部以上），右侧竖排小图为 3/4 侧身与背面全身，
长相身材与参考图完全一致。构图锁：仅一大两小三个视图、纯浅灰底、无背景无道具、无文字标注。〔负面段〕
```

用途：图生视频 / IP-Adapter / 角色 LoRA 的参考入口（视频层每镜只挂这张卡 + 服装三视图该镜套）。视频层参考图用量规则见 `../../video-producer/references/video-consistency.md` §一。
天花板注（官方论文+社区横评）：参考式（IP-Adapter/PuLID/InstantID）是「参考条件」不是身份锁；角色 LoRA（25–40 图多角度）超一致性无对手——详见 `character-asset-system.md` §五。

## 1.7 剧情立绘（i2i 挂主体 · 单人格画框锁）

```
〔风格句〕。
同一人物单人立绘（长相、身材、头身比与参考图完全一致）：〔年龄+外貌锚点逐项写死〕。
〔服装逐件写死+道具逐件〕。
〔体态/表情〕，纯浅灰背景，柔和影棚光，〔材质细节〕。
构图锁：输出画面为单格单人立绘——画面中仅一名人物、仅一个画面格，无分格排版、
无三视图排列、无特写小图、无画中画、无任何小图插图；画面下边缘切在〔取景下缘写死切点〕。
正常站姿，禁止改发型发色、禁止改身高比例、禁止新增道具、禁止背景场景。〔负面段〕
```

要点（2026-10-28 xyq 实测教训）：**i2i 会把参考图的宫格排版原样复制到输出**——「忽略参考图排版」「中景半身到膝」全被无视（实测复刻了三格+左上特写格）。解法：①构图锁用**正面画框描述**（「仅一名人物、仅一个画面格，无分格/无特写小图/无画中画」）②取景下缘写死具体切点（如「画面下边缘切在小腿中部」）③仍复刻排版时：参考图先裁成单人格再挂，或立绘改 t2i 靠锚点短语保同脸。**v2 复测验证（2026-10-28 xyq）**：画框锁生效——单格立绘、同脸服装道具全中（小偏差：信物被加珠粒，配饰类宜补「无珠无坠」）。

## 2. 即梦/Seedream 调用硬要求（官方：火山方舟《图片生成 API》2026-10-14）

调用生成前逐条过（风格段/负面段方言仍按 `shared/backends.md`）：

- **prompt 中文 ≤300 字（英文 ≤600 词）**：官方明示「字数过多信息容易分散，模型可能因此忽略细节……造成图片缺失部分元素」——超长砍形容词保要素
- **`watermark=false` 必设**：默认 true 会在右下角打「AI 生成」水印，出片素材一律显式关闭
- **返回 URL 24h 失效**：生成后立即下载转存入库，禁止只存 URL
- **无 seed 参数（官方否定结论）**：不承诺复现；「锁参数」=锁 prompt+参考图+size，重生成必抽卡
- **无 negative_prompt 参数（官方否定结论）**：排除意图写成 prompt 正向排除句（〔负面段〕在即梦/Seedream 即此）
- **无 strength/重绘幅度参数**：i2i 改动程度用「保持 X 不变，将 Y 改为 Z」指令句控制（官方示例：「保持模特姿势和液态服装的流动形状不变。将服装材质从银色金属改为完全透明的清水」）
- **多参考图按「图1/图2」序号引用输入顺序**（官方示例：「将图1的服装换为图2的服装」）：i2i 挂主体（图1）+ 服装/场景参考（图2）时点名「图1/图2」；Seedream 4.0/4.5/5.0 lite ≤14 张、5.0 pro/flash ≤10 张
- **size 推荐「档位+比例描述」**：size 传 1K/2K/4K 档位、宽高比写进 prompt 自然语言由模型适配；成本 ∝ 像素数（4K 档≈2K 档 4 倍），设定卡/立绘按用途选档
- **组图模式（sequential_image_generation）**官方定位=漫画分镜/故事板一组关联图；若用它一次出多套服装/多张关联人物图，prompt 必须写明数量与逐张内容（「生成4张……图1→图4」句式），参考图+生成图 ≤15

## 4. 出图验收清单（每批逐张过）

1. 五官锚点与人物设定逐项对照（脸/发/痣/眼型）
2. 三视图机位正交（正/侧/背真的转过去了）、全身到脚
3. 服装逐件符合「图中标注」清单
4. 手部/肢体完整（指数目、无畸变）
5. 包装/道具无品牌字样、无文字
6. 表情表四格差异可辨（同脸≠同表情）

任一不过 → 修指令写回 Notion → 从 Notion 取文重抽；禁止临时改写提示词。
