# 人物生图指令骨架（可直接复制）

> 五段式组装见 `shared/prompt-formula.md` §四；一致性两层控制见其 §二。风格段从**对应风格 skill** 取、负面段按 `shared/backends.md` 方言。〔…〕为占位符按人物设定填值。
> 注记（官方 API 事实）：即梦/Seedream 无 negative_prompt 参数——〔负面段〕在即梦/Seedream 后端=正向排除句（「画面无 X、不要 Y」式指令句），SD 系后端有负面框才放负面词。

## 1.1 基础形象设定卡（身份锚 · 合一排版 · t2i · 随剧本阶段演进）

> **一张设定卡 = 三视图 + 头部特写 + 眼部特写**，本卡=该阶段所有分镜/出视频指令的角色参考图唯一入口。造型因剧情变化（换装/负伤/装备/形态）即出新卡，命名「角色-基础形象A（EP001-010）」。表情板（§1.3）、道具卡（prop-studio，仅关键道具）独立出指令不进本卡；服装饰品随人物图直接画上，不单独出图。

【人物】〔年龄〕，身形〔头身比与体态〕，〔肤色与质感〕；〔脸型轮廓〕，〔眉形〕，〔眼型、眼尾走向、眼距、瞳色〕，〔鼻型〕，〔唇形与唇色〕，〔痣位——写死哪只眼下方〕，〔发型、刘海、长度、发色〕。五官完整露出无遮挡，双眼清晰可见。〔站姿、头身尺度、双手是否持物〕。〔对应风格 skill 中与目标图一致的肤质、发丝表现〕。

【服装与材质】服装全套：〔上装（款型、领襟扣细节，面料）〕、〔下装（型、长、褶，面料）〕、〔鞋〕、〔袜〕；配饰：〔逐件：名称、佩戴位置、材质〕。纹样〔内容、位置、疏密、颜色、工艺感〕，〔渐变起点走向等结构细节〕，〔布料与金属光泽质感的具象中文描述〕。各格同一人、同一套衣服和饰品。

【版式与机位】一张 16:9 横向人物设定图，恰好七格。七格铺满画布，外沿不留宽白边，格间仅极细白色分隔线、间距很细微，同一浅灰影棚底连续。每格只承担一个视角，逐格写机位、取景、可见性：

- 左一格·全身正面：机位与躯干中部同高，正对正面平拍，标准镜头无广角畸变；头顶到鞋底完整入画，四周留窄边；可见性：双眼平视镜头，双肩左右等宽，双手完整可见。
- 左二格·全身背面：机位正后方，与左一格同高同距；可见性：两个肩膀左右等宽，不露鼻尖或侧脸，发髻背面结构可见。
- 左三格·全身纯侧面：机位水平正侧位，被摄者面朝画框左缘，镜头与耳前鼻梁同轴，与左一格同高同距；可见性：全身纯侧格只看见一只眼，鼻尖朝向画框边缘，头顶到鞋底完整入画。
- 右上左格·头部正面特写：机位与眼同高，正对脸部平拍，头肩撑满格高；上缘切头顶上方一指宽，下缘切到锁骨；可见性：双眼平视，五官完整露出无遮挡。
- 右上右格·头部侧面特写（纯侧面正侧脸轮廓）：机位与眼同高，水平正侧位与鼻梁同轴；上缘切头顶上方一指宽，下缘切到颈肩，后缘收进完整后脑发际；可见性：耳朵位于侧脸轮廓后缘，鼻梁从侧面凸出，远侧眼完全不可见。
- 右下左格·后脑发髻特写：机位正后方与后脑同高，近距离平拍；发髻与发饰背面结构填满格；可见性：不露正脸与侧脸轮廓。
- 右下右格·眼部极近特写（微距）：机位微距，正对双眼连线；双眼、虹膜、睫毛、眼周肌肤和刘海填满画框，鼻梁上部位于下沿，画框不容纳嘴和下巴；可见性：虹膜纹理与睫毛根根可辨。不写「脸部肖像」一类会让模型补全整脸的词。

【排除】画面只有七格，无文字、无水印、宽边框、格内标注和多余人物；〔防加法句按角色写死：除规定饰品外无其他挂件等〕。不要把排除句扩写成重复的风格词表。

要点：
- 外貌锚点与人物设定一字不差；识别点=该角色最不可变的特征，是防漂的根。**同一角色跨轮/跨测试重生成时，人物描述段（脸/发/痣位/服饰）逐字冻结复用**——改一个外貌词=换人，出图即被判人物不一致（2026-11-14 用户令）。
- **画幅 16:9 严格（2026-11-13 用户令）**：设定卡全图 16:9 横幅（与实卡 2736×1536 同画幅），调用参数必传 16:9，禁止自选其他比例——画幅错=废片。
- **版式以参考图逐格标定**：苗疆原图左三格顺序为正/背/侧，右四格位置为左上正脸、右上纯侧脸、左下后脑、右下双眼极近特写。其他项目从其目标图重新标定，不套用苗疆位置。格间仅细白线；宽缝或取景错误即废。跨轮复核图像，不能仅核对提示词是否写了七格。
- **单张直出**：出图过验收即锁定 visual_id；**废片才重抽**（缺格/多格/跨格不一致/文字污染/画幅错/格间距过大/2×2 视角错任一=废），不抽卡择优。
- **只以首张整卡验收**：固定模型、比例、分辨率和单张输出；目标图只用于分析与验收，不作为生成引用。逐格记录版式、视角、取景、同人同装和材质，全部通过才记一次成功；不得将不同版本的局部优点拼成“已通过”。
- **七格指令的已知边界**：Seedream 4.7 的九个不同纯文指令版本各生成首张，共九张，均未通过苗疆旗袍整卡验收。这不能推算任一冻结指令的通过概率。眼部微距措辞可改善右下取景，却可能使左侧全身格缺失；数值坐标和字母格位会入画，禁止放入正文。修正写实风格路由可改善成人脸质感，但未使七格版式通过。相同机制的措辞微调不再作为稳定性证据；【版式与机位】逐格机位段是 2026-11-14 用户令提出的**不同控制机制**（机位几何替代结果措辞），待按同一判据实测。详细账本见 tests/material-live/苗疆人物七格根因复测-20261114.md。
- **细化字段从参考资料反推，禁凭空造**：人物/服装/机位字段=项目真实资料的描述维度并集（人设文档、绘制指令实样、实卡原图逐格、归档原始提示词），每字段标出处；通用知识只当补充（shared/lessons.md「细化字段禁凭空造」）。
- **风格两轴分开写、分开验收**：脸部设计（美型程度，如轻度美型/眼睛清亮/下颌收窄）写进【人物】，材质表现写进风格段；风格句与排除句同过图>文裁决，**排除句不得反向排除目标质感**（目标为写实禁排「真人皮肤摄影质感」，目标为 cel 系禁排「卡通」）——反向排除=两头堵=模型自由发挥（shared/prompt-formula.md §四、shared/lessons.md）。
- 材质以具象中文描述为准（SSS 类词跨模型借用无保证）；super detail 类细节词克制，过用出「AI 感」纹理。

## 1.2 装扮变体卡（服装三视图 · i2i 挂设定卡 · 每套一张人物图）

> 服装饰品随人物图穿在身上画出（唯一出处 §1.1）；换装=人物图换装出新卡。

```
〔风格句〕。
同一人物换装三视图（人物长相、身材、头身比、站姿、机位、光影与参考图完全一致）：
仅更换服装为〔套装名〕——上装〔款型+颜色+细节逐件写死〕，下装〔…〕，鞋袜〔…〕，
配饰〔逐件：名称+佩戴位置+角色自身左右，材质备注〕；
图中标注：〔部件清单〕。
构图锁：排版与参考图完全一致，只换服装不换人，禁止改发型发色、禁止改身高比例、
禁止新增道具、禁止背景场景。〔负面段〕
```

要点：**i2i 的参考图排版是锚定的**——「忽略参考图排版」这类文字指令压不住（实测输出原样复刻参考图的宫格排版）。服装三视图要的正是「排版与参考图一致」，此为正确行为；要单人格的立绘一律走 §1.7 画框锁。
**服装拆解分层写法（社区实测：mooko / catchmeta / Arcloop）**：分层展示（外套/内搭/下装/鞋）+ 装备局部放大 + 结构标注（细线引出、短硬标签、无衬线小字，如 "Ceremonial clasp" 式）+ 色板（主/辅/点缀色 + 材质标注：布料/皮革/金属）——只写「装备拆解」不写「局部放大+标注」=武器摆在旁边啥也看不清。版型逐件对应：领口/袖长/腰线/裙褶/裙摆/鞋子在三视图中一一对应；列「不可变特征」清单当硬约束；禁随机新增配饰、禁换发型、禁改服装剪裁与纹样主题。

## 1.3 表情板（i2i 挂设定卡 · 独立指令 · 6–8 格）

> 表情板不进设定卡：以基础形象设定卡为基础（i2i 挂设定卡，长相身材与参考图完全一致）单独出一条指令；格数按人设卡「表情库 6–8 种」，2×3 或 2×4 排版。

```
〔风格句〕。
同一人物表情板〔6–8〕格（长相身材与参考图完全一致，纯脸特写排版；逐格模板如下，按表情库扩格）：
【表情·〔人设标签〕】左上：眉，眼，嘴，神态收束。
【表情·〔人设标签〕】右上：眉，眼，嘴，神态收束。
【表情·〔人设标签〕】左下：眉，眼，嘴，神态收束。
【表情·〔人设标签〕】右下：眉，眼，嘴，神态收束。
每格表情解剖写满 25–40 字，四格差异明确；标签贴人设，禁通用「喜怒惊委屈」。
构图锁：逐格均为纯脸特写、同一面部结构同一五官，禁止全身、禁止空格、
禁止背景、禁止文字气泡。〔负面段〕
```

写法：每格只写眉/眼/嘴/神态收束四要素——外貌由参考图锁；同脸的解药是每格表情写满写差异。

**表情表定位（社区实测：Arcloop）**：表情表是人工审阅/绘制参照与镜头表情描述素材，**不自动提升视频/跨镜一致性**——复杂参考表不会自动赋予一致能力；常规表情直接写进出图/出视频 prompt，特别夸张、模型难理解的表情才提供表情参考。一致性靠设定卡挂载+流程兜底（真实边界见 `character-asset-system.md` §五）。
**外部标准参照（社区实测：ezcharacter / Krea）**：8 格为行业标准（平静/喜/悲/怒/惊/惧/厌/自信），对话密集项目 12 格、次要角色 6 格；单行等距或 4×2、逐格贴标签、平静为基线；**嘴型显式描述**（缩略图尺寸下嘴型比眉眼更能读出情绪）；表情网格用方形画幅。

## 1.4 面部身份卡 / 色卡

```
〔角色名〕面部身份卡：正面免冠特写，中性表情，纯浅灰背景，〔五官锚点逐项〕；
旁附色卡小条：发色〔…〕/肤色〔…〕/瞳色〔…〕/常用服色〔…〕。
构图锁：仅面部特写+色卡条，无背景无道具。〔负面段〕
```

出法（社区实测：Arcloop「先锁脸再全身」）：从已确认设计（设定卡/已锁三视图）i2i 派生，禁止独立重新生成五官——特写只为把已确认的设计交代清楚，不是重新设计。

## 1.6 角色参考卡（给视频层用的合成卡 · i2i 挂主体）

```
〔风格句〕。同一人物角色参考卡：正面大图为主体（腰部以上），右侧竖排小图为 3/4 侧身与背面全身，
长相身材与参考图完全一致。构图锁：仅一大两小三个视图、纯浅灰底、无背景无道具、无文字标注。〔负面段〕
```

用途：图生视频 / IP-Adapter / 角色 LoRA 的参考入口（视频层每镜只挂这张卡 + 服装三视图该镜套）。视频层参考图用量规则见 `../../video-producer/references/video-consistency.md` §一。
天花板注（官方论文+社区横评）：参考式（IP-Adapter/PuLID/InstantID）是「参考条件」不是身份锁；角色 LoRA（25–40 图多角度）超一致性无对手——详见 `character-asset-system.md` §五。

## 1.7 剧情立绘（i2i 挂主体 · 单人格画框锁）

```
〔风格句〕。
同一人物单人立绘（长相、身材、头身比与参考图完全一致）：〔年龄+外貌锚点逐项写死〕。
〔服装逐件写死+道具逐件〕。
〔体态/表情〕，纯浅灰背景，柔和影棚光，〔材质细节〕。
构图锁：输出画面为单格单人立绘——画面中仅一名人物、仅一个画面格，无分格排版、
无三视图排列、无特写小图、无画中画、无任何小图插图；画面下边缘切在〔取景下缘写死切点〕。
正常站姿，禁止改发型发色、禁止改身高比例、禁止新增道具、禁止背景场景。〔负面段〕
```

要点：**i2i 会把参考图的宫格排版原样复制到输出**——「忽略参考图排版」「中景半身到膝」全被无视（实测复刻了三格+左上特写格）。解法：①构图锁用**正面画框描述**（「仅一名人物、仅一个画面格，无分格/无特写小图/无画中画」）②取景下缘写死具体切点（如「画面下边缘切在小腿中部」）③仍复刻排版时：参考图先裁成单人格再挂，或立绘改 t2i 靠锚点短语保同脸。配饰类宜补「无珠无坠」，防自添珠粒。

## 2. 即梦画布 CLI 调用

调用生成前逐条过（风格段/负面段方言仍按 `shared/backends.md`）：

- **长度随当前 CLI 模型规格**：不设跨后端的中文 300 字硬上限。Seedream 4.7 的当前模型目录以实际 prompt 长度约束为准；优先删除重复形容词，保留七格定位、人物身份、服装与材质必要信息。短指令也须通过同一逐格验收，不能预设它更准确。
- **参数以当前 CLI schema 和 model list 为准**：已安装的 dreamina-canvas v1.3.0 图片节点暴露 model/mode/prompt/ratio/resolution/count/ref 等参数；没有 watermark、size、seed、strength、negative_prompt 或 sequential_image_generation flag，不把其他 API 的参数直接带入画布命令。
- **本任务的纯文单张测试**：mode=t2i、count=1、无 ref，画幅与分辨率分别用 ratio 和 resolution 指定。保存草稿后权威报价；运行后查询终态、下载真实产物并逐格验收。无显式负面参数时，少量排除意图写在 prompt 内；不得把 API 请求成功或节点 success 当作画面通过。
- **其他模式按实时能力选参**：需要 i2i 或多参考时读取对应 model list 的参考数与类型，使用当前 CLI 的类型化 ref；不得沿用另一接口的“图1/图2”或 URL 参数规则。画布资源的临时访问链接不作为唯一存档，交付文件时用 resource download 下载。

## 4. 出图验收清单（每批逐张过）

0. 画幅 = 16:9（严格，参数与产物双核）
1. 五官锚点与人物设定逐项对照（脸/发/痣/眼型）；同角色跨轮重生成与上一张逐项对照，不一致=人物漂移=废
2. 对目标图逐格核对全身机位顺序、纯侧面的 90 度轮廓、同身高同站姿及头顶到鞋底完整入画；苗疆旗袍图左侧顺序为正/背/向左纯侧。
3. 对目标图逐格核对近景位置与裁切；苗疆旗袍图右侧为左上肩以上正脸、右上肩以上向左纯侧脸、左下后脑、右下仅双眼与鼻梁。完整脸替代眼部特写、两张侧脸替代正脸、宽缝任一出现即废。
4. 服装逐件符合目标造型锚点；基础七格卡无文字标注
5. 手部/肢体完整（指数目、无畸变）
6. 包装/道具无品牌字样、无文字
7. 表情表四格差异可辨（同脸≠同表情）

任一不过 → 修指令写回 Notion → 从 Notion 取文重抽；禁止临时改写提示词。
