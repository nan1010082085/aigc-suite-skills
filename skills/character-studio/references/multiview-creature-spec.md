# 多视图参考卡与生物/宠物设计规格（multiview-creature-spec）

> 来源：用户供真人实拍项目参考卡样本 + 画布资产体系实证。示例一律占位，剧内数据住 assets.json/Notion。
> 与设定卡分工：**基础形象设定卡**（`character-prompts.md` §1.1）是身份锚；本文件的**多视图参考卡**是出视频挂载用参考图卡的标准版式，与设定卡同源互补。

## 一、多视图参考卡版式（出视频挂载用）

一张卡 7 视图，统一浅灰影棚底（#EAEAEA 级纯色）、柔光无投影、全图同一人同一套服装：

| 区 | 视图 | 目的 |
|----|------|------|
| 左区 | 按目标图标定全身正面、背面、侧面的位置；苗疆旗袍参考图依次为正/背/向左纯侧 | 服装全貌/背面结构/侧面结构 |
| 右 2×2 上左 | 头部正面特写 | 面部身份 |
| 右 2×2 上右 | 头部侧面特写（纯侧面正侧脸轮廓） | 侧面轮廓/发饰耳饰侧向形态 |
| 右 2×2 下左 | 后脑发髻特写 | 发髻/发饰背面结构 |
| 右 2×2 下右 | 脸部（眼部）极近特写 | 眼部细节/刘海 |

- 要点：全身图手部完整可见、姿态标准（一手插袋一手垂/抱书包等**全剧统一姿势**）；特写图景深浅、皮肤真实纹理（毛孔/眼下纹理/唇纹）。
- 版式是细白线分隔拼图：左 3 竖排全身 + 右 2×2 头部特写（正/侧/背/眼部），同一浅灰影棚底连续，格间仅极细白色分隔线（间距很细微，接近无缝），无宽缝/边框/相框/角花/徽章水印——素材落库保留整卡，挂载时按需裁切单视图。
- **跨视图一致性核对清单**（挂载前必查，样本实证易错点）：胸牌文字可读性、徽章/名牌位置、痣的位置（眼下哪一侧）、开衩处内搭、袖口纽扣数、背面饰品（背包/挂件）是否缺失。

## 二、服装变体轴与命名

- 命名规格：`角色名-服装变体`（如 少女-旗袍 / 少年-唐装 / 弟弟-毛衣）——**一人多变体，一变体一卡**；变体随剧情场景（礼服/校服/家居/受伤）建，不上全剧一张。
- 套装多件套写死：外套（含领型/扣型/刺绣位置）+ 内搭 + 下装 + 鞋 + 配饰（耳饰/颈饰/发饰逐件），各视图逐件一致。
- 服饰饰品随人物图穿画（唯一出处 `character-prompts.md` §1.1）；装扮变体卡=人物图换装出新卡。
- **集体校服/制服体系**（校园/公司群像剧）：全组共用同一套制服规格（外套+徽章+名牌+针织背心+衬衫+领带+裙/裤+鞋），**个人识别锚与制服解耦**——制服逐件锁死，靠发型/瞳色/痣/体态区分人。名牌属剧情实物，允许保留但不拍文字特写。
- 材质标注习惯：绒面/针织坑条/提花暗纹/金属盘扣——写进卡描述，出视频提示词按物理材质词复述。

### 时期×装扮双轴（固化标配）

- **时期轴**（剧情时间线阶段）：基础形象随阶段演进出新卡（「角色-基础形象A/B/C+阶段范围」命名）——换装/负伤/装备/形态变化都算新时期。
- **装扮轴**（场景戏服）：「角色名-服装变体」一变体一卡（见上）。
- **两轴正交组合**：不同时期×不同装扮各自成卡，随剧情演进自然积累成角色图鉴（固化标配，非冗余）：任一时期任一装扮都有现成参考可挂，出视频不再临时拼描述。

## 三、个人识别锚（每人 2–3 个不可漂移锚点）

- 发型轮廓与发色（含刘海形态/长度/蓬松度）；瞳色（特写锁）；标志性细节（眼下泪痣/颧骨痣，写死**哪只眼下方**）。
- 识别锚进三处：设定卡描述、出视频提示词「识别锚复现」、跨视图核对清单。
- 妆感可作剧种锚（如眼下淡红晕），标注为妆容设定而非皮肤瑕疵。

## 四、生物/宠物设计语言（萌系毛绒类）

- 形态基因：圆球体/椭球体 + 短绒毛（蓬松透明感）+ 玻璃质感大眼（深色瞳+大高光）+ 腮红 + 小嘴（可露单颗尖牙）+ 短小四肢。
- **单一识别特征**：每只一个记忆点（头顶独角/触角/心形尾巴/大耳），不叠加——特征越少越稳。
- **分色变体=角色区分**：同一形态基因换主色即新个体（粉/绿/白/幽灵系），色相饱和度统一柔和粉彩；分色变体各建一卡。
- **比例锚**：体型尺寸句（「巴掌大小」）写进卡与每镜提示词，全局+逐镜双重重复。
- 风格定性：3D 渲染萌系（皮克斯感）与真人实拍剧同框时写明「萌系生物写实质感融合」，禁贴纸感/扁平插画感。
- 生产通道实证：此类生物图常先用文生图工具产出再上传登记为参考资产（画布内无 generation 记录）——资产卡登记时标 `source: uploaded`，设计描述以本卡为准。

## 五、鬼怪/超自然角色两态设计

- **两态分卡**：生前态（普通人物多视图卡）+ 鬼形态（外观参考卡）分开建，命名语义区分用途（「XX样子参考」「XX生前的模样」）。
- 鬼形态设计基因：长发遮面/不见五官 + 宽松白衣 + 灰白肤色 + 半透明渐隐/边缘发光（合成质感）。
- 出视频提示词里两态引用不得混挂；同一镜出现两态=两张卡都挂并写明各自位置与虚实。


## 风格段衔接

设定卡的画面风格段按剧目风格锁取，不写死在版式里：
- 国风/新中式题材先按目标图选写实、半写实 CG 或 3D 日漫渲染，再从 `../../style-3d-anime/references/new-chinese-3d-anime-spec.md` 取适用的服饰词；仅凭服饰题材不得锁定 3D 日漫脸。
- 其余风格按 `shared/style-library.md` 风格索引取段；版式（七视图/浅灰影棚底/均匀柔光）与风格段解耦，换风格不换版式。

- 设定卡版式与逐格验收以 `character-prompts.md` §1.1 为唯一出处；本文件只定义视频挂载卡的用途，不另立苗疆格位规则。
