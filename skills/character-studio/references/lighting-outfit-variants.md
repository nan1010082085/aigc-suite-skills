# 光影变体 LIT + 换装 OUT（P2 · 按需）

> 指令见 `character-prompts.md` §1.3d / §1.3e。编号见 `shared/id-and-registry.md`。

## 光影 LIT

| 条件 | meta.lighting_key 例 | 何时做 |
|------|----------------------|--------|
| 日光室外 | 日外自然光 | 有外景正脸戏 |
| 室内暖光 | 室内暖窗光/台灯 | 默认室内 |
| 冷光/霓虹 | 夜戏冷蓝/霓虹点光 | 仅当剧本有夜戏/霓虹 |

规则：图生图挂面部或主体，**只改光影不改脸**；`lighting_key` 与 `LOC` 的「光影锁定」对齐；同场锁定场次禁止跳 key。

## 换装 OUT

1. 每套衣服独立服装三视图 → `CHAR-xxx-OUT-00n` + file
2. 该套若出对白/表情戏：另出 **表情子集**（至少平静 + 本集主情绪 EXP）
3. 分镜 `refs` 挂该套 OUT/REF + 当前 EXP，禁止混挂其他套服装图

## 验收

- LIT：同脸 + 光向/色温可读差
- OUT：与主体并排只有衣服变；领口袖长鞋对应
- 均写入 registry；人读文件名不进身份键
