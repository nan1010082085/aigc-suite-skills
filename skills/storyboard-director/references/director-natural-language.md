# 导演自然语言 · 出视频写法（现行真相）

> 2026-11-21 用户纠偏 + 全网导演/摄像/AI 蒸馏。  
> **废**：五段公文硬绑（分镜｜景别｜构图｜运镜｜画面）；构图占比工程段。  
> **立**：字段**各自独立**思考，用自然语言**织进时间线**——戏 → 机位在哪 → 怎么动 → 何时切。  
> 机位/调度/推进/覆盖/避坑细则：`director-camera-craft.md`。画幅默认 **16:9**。

## 一、字段独立（想清楚，别绑成表格腔）

下列是**独立决策**，不是必须各占一行标签：

| 字段 | 单独回答 |
|------|----------|
| 戏/动作 | 这一镜唯一主动作 + 起止状态 |
| 景别 | 相对身体框住什么（腰以上/钉双手…） |
| 机位 | 侧（地标）· 高度 · 俯仰 · 过肩哪侧肩 |
| 视线 | 画左/右 · 高低 · 贴镜或偏远 |
| 运镜 | 固定 **或** 一种运动：方式·方向·速度·落幅·动机·触发 |
| 切换 | 硬切默认；新信息是什么；入点=上镜末态 |
| 声 | 台词唯一出处；＜声＞绑动作 |

「构图意图」若需要：写进起幅/落幅/过肩关系即可，**不单开构图段**。

## 二、正文骨架（用户认可语感）

```text
【基础设定】@CHAR/@LOC/@EXP（ID）+ 当镜状态（引用≠免写）
【氛围】风格锁 + 本场光 + 16:9
【导演时间线】
镜头1：中近景平视，她握着信不拆。
摄影机缓慢推进，落在指节发白的特写；推进是为了把犹豫压到脸上。
硬切 →
镜头2：入点=上镜末态。过肩中景，门口来人；她抬头。摄影机固定。
ENDS ON：信封仍在右手。
【声音】台词…；＜动作/事件声＞…
```

多镜时间码变体见 `live-action-instruction-spec.md`——每镜仍须机位意图、运镜、切法、入点；禁构图占比段顶替。

## 三、机位与推进（织进句，不贴标签）

专业顺序：**先调度人物 → 再放机 → 再决定动不动**（详 `director-camera-craft.md`）。

推进句最低信息：触发 + 缓/急 + 落幅（相对身体）+ 动机。  
不写运动时必须写清**锁定不动**，否则模型自漂。

取景锚主体身体，禁「胸口高度」当景别（易砍头）。

## 四、切换

默认硬切；每切带来新信息。对白收紧可用切镜换景别代替镜内大运动。ENDS ON / 入点接戏。
