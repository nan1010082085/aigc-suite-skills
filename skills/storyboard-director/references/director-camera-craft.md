## 一、专业导演怎么做（顺序不可倒）

```text
1. 先调度人物（blocking）——谁进、停哪、何时起身/横穿/出画
2. 再定机位——距离 / 方向 / 高度 / 轴线一侧
3. 再定要不要动、怎么动——动机 + 剂量 + 落幅
4. 覆盖从调度里「长出来」——Master → 双人 → 过肩 → 单人 → 反应/插入
5. 纸面预演：走位有镜？终点帧机位看得见？视线配对？
```

**金标**：运镜骑在人物动作上（起身、走向窗、交文件）；问「如果固定会少什么？」——少不了就固定。【StillsLab / HSM】  
先为人表演调度、再甩给摄影解谜 = 现场翻车；AI 同理：先写清站位与地标，再写镜头。

俯视图（可用三四句文字画出来）：地标（门/桌/窗）· 每人开场位置与面朝 · 光从哪 · **轴线** · 各机位在轴哪一侧。【ByteWoops】

## 二、机位三轴（各自单独想清楚）

| 轴 | 问什么 | 写法锚 |
|----|--------|--------|
| **距离** | 全/中/近/特——观众此刻要看清什么 | 相对身体：「腰以上」「头到膝」「钉在双手」【Segmind：禁「胸口高度」当景别——模型当几何裁头】 |
| **方向** | 正/斜侧/侧/背；过肩用**靠机位那侧**的肩 | 「从她右后肩过肩拍他」；写错侧=已越轴【ByteWoops / 影视工业网】 |
| **高度+俯仰** | 镜头在哪、光轴往哪倾 | 高度相对人物（坐姿肩高/略低于站立者眼）；俯仰另写；地平线/门框竖线作证据【Staniforth】 |

### 角度卡六项（生成前可填，再织进自然语言）

1. 机位高度（相对主体）  
2. 光轴俯仰  
3. 地平线大致在哪  
4. 视线关系（看画左/右、高/低、贴镜边或偏远）  
5. 建筑竖线是否直立/汇聚  
6. 地面/天花/天空露出多少  

外加一句戏剧功能。「低角度」≠自动强势——还看表演/光/邻镜。【Staniforth / ASC 思路】

对话默认**平视眼高**；俯仰只在权力/压迫刻意时用。【Blain Brown 系口径】

## 三、推进 / 拉远怎么写（剂量）

推近：澄清细节、放大情绪、权力压上。拉远：释放、孤立、揭示环境。【Film Production Technique】

自然语言必含：

| 项 | 例 |
|----|-----|
| 触发 | 她决定拆信的瞬间；关键台词落地后 |
| 方式 | 缓推（物理位移）≠ 变焦推（透视不同，AI 更稳但偏平） |
| 剂量 | 「约半米」「极慢 3 秒内完成」——幅度宁小 |
| 落幅 | 停在「双手特写」/「肩膀以上近景」——落幅必须机位看得见 |
| 动机 | 压犹豫 / 揭示门外人 |

**静默测试**：固定会少什么？少不了 → 固定。【HSM】  
对白戏优先固定或**一个**极慢推；收紧情绪用**切镜换景别**，少镜内大运动。【ByteWoops】

位移人物：默认同速跟拍/侧跟；人走近镜头禁再同向大推（本仓已证倒退坑）。

## 四、覆盖家族与切换（字段单独）

| 镜 | 功能 |
|----|------|
| Master 双人全/中 | 建地理与轴线 |
| Two-shot | 关系距离 |
| OTS 过肩 | 对方仍在场；肩虚化、焦点在说话脸 |
| Clean single | 孤立 |
| Reaction | 台词后果——机位站在**被看物一侧** |
| Insert | 信/手/证物 |

经典收紧：Master → 过肩互切 → 关键句单人近 → **切听者反应**【ByteWoops】。  
过肩两侧焦段/松紧宜对称，除非刻意权力差。【ScreenWeaver】

**切换字段单独写**：默认硬切；须带来新信息（主体/空间/状态/视点）。只想改景别且同主体 → 优先镜内运镜。【Action-Go】  
入点 = 上镜末态；ENDS ON 写清。

合法越轴：镜内运镜带过 / 人物走位重建 / 中性镜 / 故意失衡（关系破裂）。【影视工业网 / Yale·SceneOS】

## 五、AI 导演必补字段（相对传统多写这些）

每镜提示词级建议显式出现（可织进散文，不必标签化）：

- **机位侧**（相对地标：门边 / 柜台窗侧）  
- **画内人物与朝向**（相对地标，禁「还在原位」）  
- **视线**（画左/右 + 高底 + 贴镜远近）  
- **运镜或明确「三脚架锁定、完全不动」**——不写≠固定，模型会乱漂【Shotcraft】  
- **主体动作与相机动作分句**——只写相机则人冻住；只写人则相机自创漂移【Shotcraft】  
- **终点帧**（机位必须看得见）  
- **一镜一主动作 + 一主运镜**；大动作完成约在镜长前 2/3【Screenweaver】  
- **环境微动**（尘/帘/蒸汽）可保活，主体大动宜减  

取景：**相对身体框住**（「腰以上含脸」），禁绝对高度当景别（「胸口高度」→ 砍头）【Segmind】。

## 六、避坑清单（蒸馏进自检）

| 坑 | 解 |
|----|-----|
| 五段公文绑死构图占比 | 字段独立，NL 织入；见 `director-natural-language.md` |
| 不写运镜 | 明示固定或一种运动 |
| 一镜多运镜/多事件 | 拆镜；失败只改一个变量重抽 |
| 快推/环绕/急摇怼脸 | 近脸固定或极慢推；环绕禁人脸近景（本仓） |
| 静帧错再出视频 | 静帧过检再 i2v；视频放大静帧错 |
| 头转露出未见侧面 | 先有该角度 REF/静帧，或动作减量 |
| 手崩 | 手出画或改手部特写镜 |
| 越轴 / 视线不对 | 俯视图 + 每镜机位侧与看向 |
| 过肩肩太大 | 肩占一角虚化，勿吞半幅 |
| 坐站视线高度不配 | 高者俯、低者仰，配对写 |
| 主动作拖到镜尾被切 | 主动作提前完成再余韵 |
| 多参考杀构图 | 单镜预算：REF1+EXP1+LOC1 |
| 未名人称情绪词 | 「震惊」→ 可见微动作（头偏 2cm） |
