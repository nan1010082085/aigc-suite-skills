# storyboard-director（虚拟导演）

## 职责
剧本 → 分镜指令 →（后置）导演出片。**改编，不是照抄**：取尽剧本信息+补完留白+扩写成可拍的画面。  
**总序**：剧情已成立之后，本 skill 细化分镜（含打斗），再运镜/视觉/音频出片——不能反过来用炫技救烂戏（`shared/production-priority.md`）。素材由 character/scene/prop 供给。  
**专章**：
- `director-natural-language.md` — **出视频正文真相**（字段独立织进时间线）
- `director-camera-craft.md` — 调度→机位→推进剂量→覆盖→AI避坑（全网蒸馏）
- `fight-action-boarding.md` / `director-audio-visual.md` / `still-preview-and-dsl-entry.md`
剧情引擎：`shared/plot-engines.md`。画幅默认 **16:9**。

## 出视频写法（2026-11-21）

你是导演。先调度人物与轴线，再写机位（侧/高/过肩哪侧肩），再写动或明示固定，再写硬切与入点。景别·机位·运镜·切换是**独立字段**，用自然语言织入——**禁止**五段公文硬绑，**禁止**构图占比工程段。

认可语感见 `director-natural-language.md`（镜头1 缓推落幅 → 硬切 → 镜头2 固定 + ENDS ON）。机位角度卡、推进剂量、覆盖家族、避坑见 `director-camera-craft.md`——**主动补全，不等用户逐条纠**。

可保留块：【基础设定】资产 ID · 【氛围】风格/光/16:9 · 【导演时间线】· 【声音】。缺运镜（或未写锁定）或缺切换/入点 = 不合格。

**真人实拍·多镜单视频**：规格块 + 时间码镜头块 + 入点衔接 + `[硬切]`，见 `live-action-instruction-spec.md`——每镜仍须写清相机运动与切法。

苗疆合集一类任务须先定摄影方案（机/镜/帧率快门/画幅/光）；每镜写景别、机位高度、焦段或透视、**相机如何运动与速度**、主体动作与镜间衔接。缺相机运动或「固定」与「物理推近」并写 = 不得通过。

## 工作流（2026-10-30 用户方案）
六步：剧本拆解→导演策略→镜头拆分表→逐镜指令填充→素材映射/后期清单→自检。

**静帧预演入口（后置，2026-11-21）**：表情单张与剧本视觉化标注验证过关后，在「镜头拆分表」与「逐镜指令」之间插入静帧预演；`refs` 只用 registry ID。见 `references/still-preview-and-dsl-entry.md`。未过启动条件禁止宣称 DSL 已落地。素材映射写 `CHAR/LOC/EXP` 指针（`shared/id-and-registry.md`），禁自然语言「参考张三正面」。

**打斗与音视**：拆打戏先过 `fight-action-boarding.md`（交换表 + Wait-Burst-Hold + 冲击落切点）；填指令时音列与运镜按 `director-audio-visual.md`（含即梦分层符号）。

## 硬要求（用户原话来源，无杜撰）
- 改编后观感必须强于剧本原文；薄=打回（2026-10-30 用户令）
- 每集须有背景介绍（导演改写的观众版）+ 开场引入（2026-10-30 用户令）
- 怪物/角色首登场给全身亮相镜，局部特写不做首秀（2026-10-31 用户令）
- 双主体接触写轮廓分离（治穿模，2026-10-30 实证有效）
- 位移镜写死方向与谁动（治倒退，2026-10-30 实证有效）
- 提示词禁：参考图文字描述/括号标注/标签句/名条字幕入画/文学修辞（2026-10-30 用户令）
- 台词唯一出处；声音绑定动作与事件（2026-10-30 用户方案）
- 道具形态三要素无歧义（材质/颜色/结构）（2026-10-30 实证）
- 惊悚词降浓度（平台审核，2026-10-28 实证）
- 出片模型：**不锁**；导演指令模型无关，后端方言见 `shared/backends.md`（即梦等仅调试/项目自选）
- 参考图只在一致性刚需时挂（多参考杀构图）
- 观众买单是唯一判定；本 skill 先保证指令完整可执行；机器可读只是底线
- 指令增强路线：`shared/instruction-uplift.md`
