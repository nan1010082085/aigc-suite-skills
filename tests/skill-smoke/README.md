# skill-smoke —— skill 出指令冒烟测试

目的：验证 skill 产出的指令能过**合规闸**（prompt_selfcheck），且校验**不拦创作**（2026-11-05 用户令：检查=合规，不是限制模型/发挥/创作）。

## 测试样本

| 文件 | 来源 skill | 说明 |
|---|---|---|
| `sample-video-instruction.md` | storyboard-director + live-action-instruction-spec（出视频指令） | 多镜单视频指令：全局规格块+【光线】+素材引用行+3 连镜（详式，时间码衔接，逐镜限制防漂移）+台词行。**故意写长、写满细节、自由发挥叙事**——照样过检，证明合规闸不卡创作 |

样本为通用占位内容（无剧名、无真实资产），节点引用用 `{{node:node_pet01}}` 一类占位符。

## 运行

```bash
./run.sh
# 等价于：
# python3 ../../tools/prompt_selfcheck.py --mode video sample-video-instruction.md
```

预期：无输出、退出码 0（= 通过）。有任何问题清单输出则退出码 1。

## 合规闸拦什么 / 不拦什么

- 拦（合规风险）：平台审核违禁词、裸英文运镜（后端不识别）、多镜缺时间码（机器不可读）、refs>9（素材挂载风险）、重复块（拼装手误）、每镜 <250 字（信息量保底）
- 不拦（创作自由）：字数无上限、风格/叙事/镜头语言任意发挥
